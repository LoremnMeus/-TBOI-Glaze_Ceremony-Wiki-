## 效果

**在商店里变成身无分文时，平等协议会把剩余的收费资源商品改成道具底座。**

只要角色在商店中持有 **0** 枚硬币：

- 收费的心、钥匙、炸弹、电池等非道具商品会变为随机道具；
- 原本已经是道具的商品不会因此再次改写；
- 在商店内把最后一枚硬币花掉，同样可以立即触发这次转换。

## 使用技巧

- **不必在进商店前就保持 0 硬币。** 可以先购买想要的商品，把最后一枚硬币花掉；硬币降到 0 后，尚未处理的收费资源商品会立即变成道具。
