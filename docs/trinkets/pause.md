## 效果

**「暂停？」用本局下一次真正暂停，换取即时五项属性提升。**

| 属性 | 数值 |
| --- | ---: |
| {{Speed}} 移速 | +0.05 |
| {{Tears}} 射速 | +0.15 |
| {{Damage}} 伤害 | +0.5 |
| {{Range}} 射程 | +1 |
| {{Luck}} 幸运 | +1 |

打开真正的暂停界面后失去此饰品；睡床造成的特殊暂停状态不会触发。
