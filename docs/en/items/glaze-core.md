## Mechanics

## Effects

Glaze Core has no fixed form. When it appears naturally, it picks another collectible from its own item pool as a disguise.

Until revealed, it tries to look like that item—including sprite, name, description, and some price presentation.

After pickup, what you actually hold is Glaze Core:

* On use, gain the current disguised item's effect for the room.
* Leaving the room removes the temporary effect.
* Each use has a **5%** chance to permanently turn Glaze Core into the real item it is imitating.

Glaze Core will not choose active items as normal disguise targets.

## Notes

* The pedestal you see may not be its true identity; before the first pickup, even the item text joins the disguise.
* After picking up Glaze Core, looking at it again shows the real temporary-copy rules.
* If it cannot find a valid disguise target, it falls back to a safe default.
* It only copies the one item it is currently imitating; it does not re-roll the target on every use.

## Synergies

### {{Collectible:584}}

Using Glaze Core has a low chance to spawn a wisp matching the current disguised item.
