## Effects

The True Name is a guessing game about the **next item-pool draw**.

On use, open the full collectible picker and choose what you think the pool will draw next; then the game actually rolls once and compares.

## Correct

If they match: spawn that item plus {{Collectible:628}} Death Certificate.

## Wrong

If they differ: the prediction fails and you do not get the jackpot (the true roll is shown as failure feedback).

## Why guess

This is not a random 3-choice. Pool knowledge, depleted items, and pool state can inform a guess; exact hits are rare, which is why the prize is extreme.

## Trivia

- Points to the Yu-Gi-Oh! card of the same name, "The True Name".
- Both the card and this item reward correctly guessing designated content; in Isaac it is harder to pre-arrange the answer the way a card game can.
