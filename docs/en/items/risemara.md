## Effects

Risemara packs a **reset marathon** into one item. On pickup it rolls grades for six basic stats; if the result is bad, put it back on the original pedestal and pick it up again until the character is worth starting with.

Stats covered: damage, tears, range, speed, luck, shot speed. Each can be positive, neutral, or negative, and grades show immediately on pickup.

## Grades

Each grade multiplies that stat's max amplitude:

| Grade | Multiplier |
| --- | ---: |
| High up | +100% |
| Mid up | +2/3 |
| Small up | +1/3 |
| Neutral | 0 |
| Small down | −1/3 |
| Mid down | −2/3 |
| High down | −100% |

Max amplitudes:

| Stat | Max |
| --- | ---: |
| Damage | ±3 |
| Tears | ±1.5 |
| Range | ±4.5 |
| Speed | ±0.6 |
| Luck | ±6 |
| Shot Speed | ±0.6 |

## Reroll

Pickup remembers the original empty pedestal. Near it, Isaac lifts Risemara; colliding puts it back. Picking it up again rerolls all six grades. It can be returned and picked up repeatedly with no reroll limit.

## Notes

- Rerolls replace the whole set; you cannot keep only one grade.

## Trivia

The name and fantasy echo Yu-Gi-Oh's “Rite of Aramesir” / Adventurer theme, while the gameplay is a direct toy version of the common “reset marathon”—rerolling until the starting stats feel right.
