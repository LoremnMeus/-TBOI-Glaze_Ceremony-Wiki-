## Mechanics

### Effect
Walk near to lift a contract. The HUD shows **gain amount + pickup ghost → amount that will be taken + ghost**. Switch with left/right, walk in to confirm.

Each beggar offers 3 random contracts and trades once.

- {{Coin}} **Tomorrow's Coins**: +10¢ now; later takes 12¢ by face value (nickel 5, dime 10; overpay is interest).
- {{Key}} **Tomorrow's Keys**: +3 keys now; later takes 4 (double keys count as 2).
- {{Bomb}} **Tomorrow's Bombs**: +3 bombs now; later takes 4.
- {{SoulHeart}} **Tomorrow's Life**: +2 soul hearts now; later takes 3 red heart pickups.

Debt starts immediately, persists across rooms and floors, until paid. Inventory is never deducted. New run / R restart clears it.

Natural spawn: 12% / 10% / 6% to replace vanilla beggars in chapters 1 / 2 / 3; none from chapter 4 on.

### Notes
"Tomorrow" means future pickups from this moment, not only the next floor.
