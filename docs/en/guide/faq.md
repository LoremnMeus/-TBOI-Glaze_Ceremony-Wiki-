# FAQ

## Why does Chapter I not start after I finish the Prologue?

This is expected in the current release.

The formal story scope of `alpha-0.1` ends with the Prologue. Chapter I, “What We Seek,” is still in development and does not begin during normal play in this Alpha build.

## Is this already the complete remaster?

No.

The project is still in Alpha testing. Items, cards, story infrastructure, character compatibility, UI, and other systems have received substantial rework, but the overall remaster is still in progress.

## Are all characters fully remastered?

No.

Different characters are at different stages. Some mainly need smaller balance, control, compatibility, or presentation adjustments, while others still require larger pieces of work.

Tainted Qing currently has basic vanilla-item compatibility, but her aircraft skins and compatibility with this mod's custom items and mechanics are still unfinished.

## Why are some Wiki pages behind development?

The public Wiki should document mechanics that can actually be verified against the current build.

The existence of development code does not automatically mean a feature is ready for players. Pages are expanded as their behavior is verified.

## When will the mod return to the Steam Workshop?

There is currently no announced release date.

The plan is to return to the Steam Workshop once Chapter I, character refinement, and the other major remaster work meet the standard for a formal release.

Until then, public GitHub builds are the main Alpha testing channel.

## Where should I report bugs?

Use the public GitHub Issues page:

https://github.com/LoremnMeus/-TBOI-Glaze_Ceremony-RGON-/issues

This is also the main public feedback channel during development.

## What should I include with a crash report?

Please include as much of the following as possible:

- mod version;
- Isaac version;
- REPENTOGON version;
- character used;
- floor or room;
- what you were doing immediately before the crash;
- other enabled mods;
- relevant log files;
- the matching `.dmp` crash dump.

If you are unsure which files are relevant, attaching files created around the crash time is still useful.
