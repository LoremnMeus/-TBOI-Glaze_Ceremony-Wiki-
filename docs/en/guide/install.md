# Installation & Requirements

## Current version

The current public build is **alpha-0.1**, a public testing build of the remaster project.

Normal story progression currently ends after the Prologue. Chapter I, “What We Seek,” is still in development.

## Game requirements

Use a version of *The Binding of Isaac: Repentance+* currently supported by REPENTOGON.

The full mod requires **REPENTOGON**. Without it, some features may not work or may only load through limited compatibility behavior.

## Download

Current Alpha builds are available from the public GitHub Releases page:

https://github.com/LoremnMeus/-TBOI-Glaze_Ceremony-RGON-/releases

Player Wiki:

https://loremnmeus.github.io/-TBOI-Glaze_Ceremony-Wiki-/

## Manual installation

After downloading the release package, place the:

`Qing_remaster`

folder inside Isaac's `mods` directory.

The final layout should look similar to:

`mods/Qing_remaster/main.lua`

Do not leave an additional archive folder around the mod directory.

## Updating

Close the game before updating, then replace the previous `Qing_remaster` folder with the new release.

Do not merge old development files, legacy Glaze Ceremony files, and the current remaster directory together.

## Troubleshooting

First check:

- whether your game version is supported by your REPENTOGON build;
- whether REPENTOGON loaded correctly;
- whether the mod is installed in the correct directory;
- whether old files remain from a previous version;
- whether another enabled mod affects the same mechanic.

For the known startup black-screen issue, see:

[Black screen after launch](/en/troubleshooting/black-screen)

For other bugs and compatibility problems, use:

https://github.com/LoremnMeus/-TBOI-Glaze_Ceremony-RGON-/issues

If the game crashes, please attach the relevant log and `.dmp` files when possible.
