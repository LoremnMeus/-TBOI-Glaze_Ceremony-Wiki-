# About

**Glaze Ceremony: Promised Land** is the remastered and continued-development version of the *Glaze Ceremony* content mod for *The Binding of Isaac: Repentance+*.

The public build is currently in **Alpha testing**. This stage focuses on rebuilding legacy content, resolving long-standing issues, and gradually establishing the new story, character compatibility, UI, and shared systems. Some parts have already received substantial reworks, while others are still being refined.

## What alpha-0.1 includes

The current build includes the items and cards from the original Glaze Ceremony release together with the reworks, fixes, and new mechanics completed so far.

For story content, `alpha-0.1` formally includes the complete **Prologue**.

Chapter I, **“What We Seek,”** and the story that follows are still in development and are not available through normal play in this Alpha release.

## Character status

Character remaster and compatibility work is still ongoing. Different characters are currently at different stages of refinement.

Some characters mainly need further balance, control, presentation, or compatibility adjustments. This does not mean the full character roster has reached its final remastered state.

**Tainted Qing** currently has basic compatibility with vanilla items, but two major areas remain unfinished:

- aircraft skins and related visual adaptation;
- full compatibility with this mod's custom items and mechanics.

Character behavior, balance, compatibility, and presentation may therefore continue to change during the Alpha period.

## Current release channel

The public GitHub build is currently the main Alpha testing channel.

Once Chapter I, character compatibility and refinement, and the other major remaster work reach release quality, the mod is planned to return to the Steam Workshop.

Until then, public builds should be treated as development-stage Alpha releases.
