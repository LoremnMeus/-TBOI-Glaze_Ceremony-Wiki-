## Effects

When used, randomly selects one special room type on the current floor that has not already been selected and reveals every room of that type.

The first time you enter one of those rooms, several portals appear. They can lead to other special rooms on the floor or to {{System:special-destinations|special destinations}}.

Each selected room type can trigger only once per floor.

## Rules

- Only non-default room types that actually exist in the current dimension can be selected.
- A room type already selected on this floor cannot be selected again.
- If no new special room types remain, the card reveals the entire floor instead.
- Normally **4–5** portals are generated; some results create more.

## Synergies

### {{Collectible:451}}

Generates **2 additional portals** when the selected room type is first entered, and increases the chance of special destinations.
