## Effects

When used, sacrifices all items obtained in Angel Rooms during the current run that you still hold.

Each successfully sacrificed item spawns 1 item from the {{DevilRoom}} Devil Room item pool.

Whether an item can be sacrificed depends on where it was obtained, not on which item pool it normally belongs to. Any item taken from a pedestal in an Angel Room counts.

Items you have already lost are not sacrificed.

## Synergies

### {{Collectible:451}}

If a sacrificed item can create a corresponding item wisp, it also leaves behind 1 such wisp.
