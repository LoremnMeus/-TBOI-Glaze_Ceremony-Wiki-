## Effects

On use, the player repeatedly spits out {{Heart}} that can be **safely spent**, turning them into rotten hearts behind the player. Each rotten heart created this way continuously releases toxic fog that damages nearby enemies.

These rotten hearts are not merely part of the initial attack: as long as one remains on the ground, its linked toxic fog remains with it. If the heart persists into another room, the fog is restored around it there as well.

## Notes

* Each normal spit spends **1 red heart**. The effect will not exhaust the player's final health reserve simply to create another rotten heart.
* Once no more red hearts can be safely spent, each generation check still has a **10%** chance to spit an extra rotten heart for free.
* Free rotten hearts have the same toxic-fog effect as hearts created by spending health.
* If one of these rotten hearts is picked up or otherwise removed, its linked toxic fog fades away as well.

## Synergies

### {{Collectible:451}}
