## Effects

On use, the player **drops all active items, cards/pills, and trinkets**. Up to **6 resources** remain in the room in a special form, creating an item array that persists with the player between rooms.

Resources in the array still retain their normal functions: active items can still be used and continue gaining charge, cards and pills can still be consumed, and trinkets remain active. When standing near several resources, one is selected automatically; selected actives and cards/pills can be used with their normal active-item or pocket-item controls.

While the effect is active, the array can also be managed directly:

* Select a nearby ground active item, card, pill, or trinket and press **{{ButtonRT}}** to move it into the array.
* Select a resource already in the array and hold **{{ButtonRT}}** to return it to the ground.

No additional resources can be added once the array reaches its capacity.

If the player **holds any active item, card/pill, or trinket again**, the array ends and every resource still stored in it is returned to the ground. Using XIII - Death? again also ends the current array before creating a new one.

## Notes

* If the player is carrying more resources than the array can hold when the card is used, active items enter first, followed by cards/pills, then trinkets. Anything that does not fit is dropped normally.
* Paid resources still require their normal payment when moved into the array. If the target belongs to an exclusive option group, moving it into the array counts as choosing that option, so the other choices disappear normally.
* Active items preserve their charge state and continue receiving normal room-clear charge while in the array. With {{Collectible:356}}, overcharge is preserved as well.
* Returning an active item to the ground does not reset its stored charge.
* An active item that originally came from a secondary or pocket active slot returns to that same slot when picked up again.
* Returning a resource from the array to the ground does not end the effect by itself. Picking it up again does, because the corresponding inventory slot becomes occupied again.
