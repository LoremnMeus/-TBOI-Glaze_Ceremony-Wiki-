## 效果

琉璃硬币会缓慢吸引附近的其他掉落物；玩家拾取时再按概率结算硬币。

| 结果 | 概率 |
| --- | ---: |
| 1¢ | 90% |
| 5¢ | 10% |

吸引只会推动附近非商店掉落物，不会替玩家自动拾取。商店货不受吸引。

持有 {{Item:crown-of-the-glaze}} 且冠冕满层时，高面额结果改为 **15¢**（仍为 10%）。
