# 蓝图与 Air Flight

「蓝图」是 {{Character:sp-w-qing}} 的核心成长系统。青本人无法进行普通直接攻击，因此一局中取得的道具可以被蓝图占用，成为飞行器的底座或模块。

整个系统可以概括为：

> 制造机体 → 安装模块 → 编入出战队列 → 用准星指挥战斗

## 先理解这四件事

- **底座决定机体有多强。** 它提供模块槽与整体属性框架，但不会直接赋予原本道具效果。
- **模块决定机体会什么。** 武器、属性、宝宝与特殊行为都来自实际装入的模块。
- **编队决定谁出战。** 控制带宽不足时，队列越靠前的机体越优先。
- **准星决定它们怎么打。** 阵型控制机体留在身边还是展开，火控决定自行索敌还是攻击指定位置。

## 三个页面

| 页面 | 用途 |
| --- | --- |
| 编队 | 决定哪些飞行器出战，以及带宽不足时的优先顺序 |
| 制造 | 在 Air Flight 与 Air Terror 等已开放机体中选择目标并制造新单位 |
| 仓库 | 查看已有机体，重新配置底座与模块，或拆除机体 |

短按蓝图会切换自动/压制火控；长按至进度完成才会打开管理面板。具体指挥按键见 {{Character:sp-w-qing}}。

## 制造与第一架机体

制造时先选择目标机体，再安排底座与模块。Air Flight 与 Air Terror 当前都已登记为可正常制造的目标，并使用不同的模块布局。

青的第一架真实 Air Flight 是特殊情况：它不需要底座，固定按品质 2 的底座处理，具有 3 个模块槽与标准基础倍率。这样角色不必先占用一件道具，便能建立最基本的攻击能力。

已有至少一架真实机体后，之后每架机体固定需要占用 1 件真实道具作为底座。

## 底座

简单来说，底座决定“这架机体有多好”，模块决定“这架机体会什么”。

底座位于机体下方，决定机体的基础品质、模块槽数量和整体属性倍率；**底座本身的道具效果不会作为模块应用给飞行器**。

| 底座品质 | 模块槽 | 整体属性倍率 |
| ---: | ---: | ---: |
| 0 | 1 | 0.80× |
| 1 | 2 | 0.90× |
| 2 | 3 | 1.00× |
| 3 | 4 | 1.15× |
| 4 | 5 | 1.30× |

这里的倍率会共同影响机体的伤害、射速、弹速、射程、幸运和移动速度等基础战斗属性。高品质道具作为底座的价值在于更好的机体框架，而不是复制该道具原本的效果。

## 模块

只有真正放入机体周围模块槽的道具才参与攻击 Profile，使对应飞行器获得武器、属性、宝宝或特殊行为。不同机体拥有彼此独立的配置：一架可以集中承担主要输出，另一架则可以围绕特殊弹种、宝宝或辅助效果构筑。

具体兼容项目会继续扩充；本页只解释模块系统的共同规则，不列出完整兼容矩阵。

## 道具占用

**一件道具只能同时服务于一架机体。** 蓝图通过“占用”记录这件道具当前属于哪个配方；它不会真的从背包中删除，但在释放之前不能同时成为另一架飞行器的底座或模块。

删除机体，或把道具从配方中卸下后，对应占用会随当前配方记录立即释放；由于真实道具本来仍在背包中，它会重新成为可分配资源。

## 进阶：道具原型

持有蓝图时，游戏中的「道具原型」拾取物可以把对应道具记录加入原型库存。原型拥有独立身份，可以代替真实道具参与模块配置，并且不计入角色真实背包中的道具份数。

同一份原型仍然只能被一个配方占用；卸下或删除对应机体后，它也会重新回到可分配状态。原型是一份额外的配方资源，而不是无限复制许可。

## 控制带宽

青拥有有限的控制带宽。当前正常规则为：

| 内容 | 带宽 |
| --- | ---: |
| 基础容量 | 3 |
| 普通机体 | 1 |

当前没有普通模块额外提高带宽成本，因此基础状态下通常最多同时维持 3 架机体出战。已经制造却没有获得有效带宽的机体不会消失，而会进入待命，回到青附近并停止正常索敌和攻击；其所属战斗型宝宝也会停火。

## 编队顺序

编队页同时保存“希望启用”与“实际出战”两种状态。系统按编队顺序依次分配带宽；容量不足时，排在前面的机体优先出战，后面的机体进入待命，但系统不会偷偷取消玩家对它们的启用意愿。

带宽重新充足时，仍处于“希望启用”状态的待命机体会按编队顺序重新获得出战机会。

## 阵型与火控

指挥机群时，只需分别回答两个问题：**“飞行器在哪里？”**和**“它们攻击谁？”**阵型回答第一个问题，火控回答第二个。

| 阵型 | 火控 | 主要用途 |
| --- | --- | --- |
| 巡航 | 自动 | 展开并自行寻找合法目标 |
| 护卫 | 自动 | 留在青的两翼进行防护性攻击 |
| 巡航 | 压制 | 展开机群并集中攻击准星位置 |
| 护卫 | 压制 | 保持两翼阵型并向准星位置开火 |

压制不会自动改变阵型，护卫也不会让准星消失。玩家可以分别决定“机体在哪里行动”和“机体自行找目标还是攻击指定位置”。

## 仓库与改装

仓库保存所有已经制造的机体。玩家可以重新安排底座与模块、改变机体定位，或拆除不再需要的机体；制造时的选择并不会把整局配置永久锁死。

若机体所需的真实道具或原型已经不再可用，其配方会失去完整性，机体不会继续按一份不存在的完整配方正常作战。重新补齐资源后，系统会再次按当前配方恢复和接管机体。

## 使用技巧

- 高品质道具作为底座会增加槽位和基础倍率，但不会提供其原本道具效果。
- 构筑完整的机体若排在队列末尾，仍可能因带宽不足进入待命。
- 需要指定目标或攻击非敌对障碍时使用压制；普通清怪可使用自动火控。
