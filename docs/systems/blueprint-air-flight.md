# 蓝图与机群

{{Character:sp-w-qing}} 无法直接攻击，而是把本局获得的道具投入“蓝图”，制造并改装自己的机群。玩家决定每架机体如何组装、哪些机体出战，再通过准星、阵型和火控指挥它们战斗。

一件道具在蓝图中可以成为底座或模块：底座决定机体规模和基础性能，模块则把道具的战斗能力装入机体。

## 蓝图怎么玩

- **制造：** 用道具建立新的机体。
- **改装：** 底座决定机体规模，模块决定攻击方式和附加能力。
- **编队：** 决定有限带宽优先供给哪些机体。
- **指挥：** 用阵型与火控决定机体在哪里、攻击哪里。

## 机体

机体是通过蓝图制造的独立战斗单位。每架机体按照自己的底座与模块计算伤害、射速等战斗属性，而不是直接继承青本人的攻击属性。

玩家可以保存许多机体，但能够同时出战的数量受控制带宽限制。没有分到带宽的机体不会消失，而会回到青身边待命。

## 制造机体

蓝图制造的所有机体都以 {{Item:air-flight}} 为基础框架。每架机体的差异来自底座、模块与编队，而不是预设职业。

制造页进入「新建设计」，再选择底座并配置模块。制造完成后，机体会进入仓库与编队，之后仍可免费重新安排配置或拆除。完成的设计按序列显示为 **空行01号、空行02号……**（可再附加型号字母）。

### 第一架基础机：AF-00 技术

{{Item:air-flight}}（空行零号·试作型）是这套平台的原型技术。青制造的第一架正式设计不需要占用底座道具，固定按品质 2 底座计算，拥有 3 个模块槽和 1.00× 基础倍率。

这让青在尚未积累足够资源时，也能获得最基本的攻击能力。仓库中已有至少一架正式机体时，继续新建设计需要为底座分配一件真实道具。

## 用道具组装机体

### 底座

底座决定模块槽数量和整体属性倍率，但**不会把该道具本身的特殊效果赋予机体**。

| 底座品质 | 模块槽 | 整体属性倍率 |
| ---: | ---: | ---: |
| 0 | 1 | 0.80× |
| 1 | 2 | 0.90× |
| 2 | 3 | 1.00× |
| 3 | 4 | 1.15× |
| 4 | 5 | 1.30× |

倍率共同影响机体的伤害、射速、弹速、射程、幸运和移动速度等基础属性。把高品质道具用作底座，意味着这份道具暂时不能再作为模块使用；玩家需要在更多槽位与该道具的独特模块能力之间取舍。

### 模块

只有放入模块槽的道具才参与该机体的战斗构筑。不同机体的配置彼此独立，模块大致分为：

| 模块类型 | 作用 |
| --- | --- |
| 武器模块 | 改变机体的主要攻击方式，如激光、蓄力攻击或特殊弹道 |
| 属性模块 | 修改该机体自己的伤害、射速、弹速、射程等属性 |
| 宝宝模块 | 让宝宝归属于对应机体，并随它出战或待命 |
| 特殊模块 | 加入环绕物、受伤反应、光环或其他专门实现的行为 |

完整兼容范围会由独立的蓝图兼容表承担；本页只说明所有机体共用的组装规则。

模块效果以蓝图的实际兼容为准；部分道具会被转换成适合机体使用的对应行为，并不一定逐字复制原版效果。同一底盘也可以走出硫磺火主炮、妈刀近战、宝宝母舰或炸弹机等完全不同的配置——差异来自模块，而不是第二种底盘。

### 道具占用

每份真实道具同一时间只能分配到一个底座或模块位置。

里小青本人无法普通攻击，因此许多攻击方式道具即使仍在物品栏，也不会让本人恢复泪弹攻击。只有装入模块槽后，它们才会按蓝图兼容转化为对应机体的攻击能力。

卸下模块或拆除机体会立即释放对应占用，使道具重新成为可分配资源。

::: tip 道具不会真的消失
蓝图只记录一份道具当前被哪个配方使用。它仍然属于青并保留原本能够对青生效的被动效果，但不能同时再成为另一架机体的底座或模块。
:::

### 原型模块

原型是一份额外的模块安装权。

它不增加玩家实际持有的道具，也不能作为底座。每份原型只能被一架机体占用一次。

生成方式、商店价格与掉落规则见 {{Pickup:blueprint-prototype}}。

### {{Collectible:619}} 镜像槽

当 {{Character:sp-w-qing}} 持有 {{Collectible:619}} 时，每架飞行器额外获得 **1 个镜像模块槽**。

- 只能引用玩家**当前实际持有**、且已支持蓝图兼容的道具，**不能**作为底座。
- **不占用**该道具的蓝图分配额度：同一件真实道具仍可同时作为另一架机体的底座或普通模块。
- **多架机体可以同时镜像同一件道具**；每架机体只有这一个镜像槽。
- 失去被引用的原道具后，对应镜像立即失效，直到重新获得该道具或换装。

与原型不同：原型是可独立分配的制造资源；镜像只是对已拥有道具的技术投影，不能凭空产生模块。

## 管理机群

### 蓝图的三个页面

| 页面 | 用途 |
| --- | --- |
| 编队 | 安排机体的启用状态与带宽分配顺序 |
| 制造 | 「新建设计」并制造一架新的空行 |
| 仓库 | 查看已有机体，重新配置底座与模块，或拆除机体 |

短按蓝图切换自动/压制火控；长按至进度完成才打开管理面板。完整操作见 {{Character:sp-w-qing}}。

### 控制带宽

**制造数量不等于同时出战数量。** 青默认拥有 3 点控制带宽，当前普通机体各占 1 点，因此通常能同时维持 3 架机体出战。

当前没有普通模块增加额外带宽成本。超过容量的机体会待命，停止索敌和攻击；归属于它们的战斗型宝宝也会停火。

### 编队与待命

玩家可以让超过带宽上限的机体保持启用。系统从编队最前方开始分配带宽，排不下的机体暂时待命；带宽空出来时，它们会自动按顺序补位。

<WikiScreenshot src="/images/screenshots/systems/blueprint-fleet/formation.jpg" :ready="true" alt="四架机体的编队页，其中三架出战、一架因带宽不足待命" caption="控制带宽决定同时出战数量；排在后方且暂时没有带宽的机体仍会保留并等待补位。" />

已制造的机体可以随时在仓库重新配置或拆除，不收取额外费用。

## 指挥战斗

控制机群只需要分别决定两件事：

- **阵型：机体在哪里？** 巡航允许机体展开行动；护卫让它们留在青的两翼。
- **火控：机体打哪里？** 自动让机体寻找合法目标；压制让它们集中攻击准星位置。

| 阵型 | 火控 | 表现 |
| --- | --- | --- |
| 巡航 | 自动 | 展开并自行寻找合法目标 |
| 护卫 | 自动 | 留在青的两翼进行防护性攻击 |
| 巡航 | 压制 | 展开机群并集中攻击准星位置 |
| 护卫 | 压制 | 保持两翼阵型并向准星位置开火 |

压制不会自动改变阵型，护卫也不会让准星消失。

<WikiScreenshot src="/images/screenshots/systems/blueprint-fleet/combat.jpg" :ready="true" alt="里小青用准星指挥多架机体战斗" caption="准星决定指挥位置；阵型与火控分别控制机体的站位和攻击目标。" />

## 使用技巧

- 把最依赖持续出战的机体放在编队前面；排在后方的完整机体仍可能因带宽不足而待命。
- 自动火控适合普通清怪；需要集中打击火堆、便便或指定位置时切换压制。
- 需要不同攻击构筑时，可以制造备用机体并通过编队调整谁先获得带宽。
