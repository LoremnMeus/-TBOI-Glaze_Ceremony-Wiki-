# 永久

本模组中，**永久修改**指会跨越不同游戏局保留的长期变化。新开一局、换角色或退出游戏后，这些变化仍可能继续生效，直到被对应机制消费、覆盖或清除。

这与「本局内持续到结束」的效果不同——例如拖延症在本层内累积的攻击，或六罪论在本局内记住的七罪小 Boss——后者不会影响下一局。

## 当前永久机制

| 道具 | 永久记录 |
| --- | --- |
| {{Item:spectralsword}} | 被改写的道具名称与拾取副标题 |
| {{Item:remaster}} | 已建立的楼层传送渠道 |
| {{Item:colorblindness}} | 下局开局时从道具池移除的「点踩」列表 |
| {{Item:qings-faceted-market-diamond}} | 跨局商店售价与上次成交价 |
| {{Item:book-of-future}} | 未来逃逸后尚未完成的累计品质 |

各条目的具体触发与清除方式，请查看对应道具页面。

## 下局生效

有些永久修改不会立刻影响当前局，而是在之后的新局中应用；只要它会写入长期档案并跨局保留，仍属于「永久」机制。

::: info 尚未实装
未来可能出现能够统一管理永久修改的道具机制；实装前以上条目以各自页面为准。
:::
