# 透特牌

「透特牌」是琉璃圣典中的一套自定义塔罗牌体系。它们与原版塔罗牌共享单次使用的基本形式，却拥有独立的牌面、效果和相关道具，并不是普通塔罗牌的另一种显示方式。

## 正位与逆位

同一张透特牌可以拥有正位与逆位。两者不是单纯的视觉翻转，而是效果与收集状态都彼此独立的牌面。

因此，获得某张正位牌并不代表已经获得它的逆位。在 {{Item:book-of-thoth}} 等需要记录牌面的系统中，两者会分别登记和计算。

## 与普通塔罗牌的关系

透特牌属于独立卡牌族，但部分机制会在普通塔罗牌与透特牌之间建立获取渠道。

最明显的例子是 {{Item:book-of-thoth}}：持有它时，普通塔罗牌生成有机会被替换成透特牌，替换率会根据卡册中尚未登记的牌面比例变化。因此原版 Tarot 与 Thoth 并非同一个卡池，也不是所有角色都固定拥有透特牌出现率。

## 透特之书与牌面收集

{{Item:book-of-thoth}} 是目前与透特牌关系最直接的系统型道具。它会记录玩家遇到的牌面，将正位与逆位分别登记，并通过「启示」重新调用已经收录的结果。

具体的卡册、启示与牌阵操作见透特之书页面；本页只说明它怎样影响透特牌的出现。

### 未登记牌面的生成倾向

持有透特之书、且系统需要选择生成一张透特牌时：

| 牌面状态 | 基础权重 |
| --- | ---: |
| 尚未登记 | 3 |
| 已登记 | 1 |

书会因此明显推动玩家补齐尚未见过的牌面，而不是完全均匀地重复旧牌。

### 普通塔罗牌替换

持有透特之书时，普通塔罗牌被替换为透特牌的概率等于“尚未登记牌面占全部透特牌面的比例”，最高为 50%。

卡册很空时更容易建立透特牌获取渠道；随着牌面逐渐补齐，替换概率也会自然降低。这是透特之书带来的生成规则，并非透特牌系统对所有玩家生效的全局掉落率。
