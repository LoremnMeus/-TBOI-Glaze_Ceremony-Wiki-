# 琉璃

琉璃是一组共享视觉和机制主题的特殊内容，包括琉璃掉落、宝箱、炸弹、敌人以及与它们交互的道具。

不同琉璃内容拥有各自效果，并不代表持有多个琉璃内容会自动组成套装奖励。具体规则以各个条目页面为准。

## 琉璃掉落

当前公开的琉璃掉落包括心、硬币、炸弹、电池、福袋、宝箱等特殊变体。

它们可以通过不同的琉璃道具、卡牌和转换效果生成。

## 琉璃之宝箱

{{Pickup:glaze-chest}} 会在本层其他房间生成对应钥匙，找到钥匙后才能打开。
