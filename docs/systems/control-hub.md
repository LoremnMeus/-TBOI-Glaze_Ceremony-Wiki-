# 控制中枢

「控制中枢」是 {{Character:zeiz}} 专属的管理系统。它把一局游戏中的部分规则交给一组具有不同偏见的管理员：

> 任命管理员 → 愚见生效 → 行为引起兴趣 → 提案准备

它并不是传统的“获得能力、消耗资源、主动使用”循环，而是一套会随着楼层推进不断叠加的治理规则。

## 管理员

每次需要进行新任命时，系统会从尚未任命、并且允许作为候选的管理员中随机选出至多三名。

一旦某名管理员被任命，它会保留在本局的管理员列表中，不再参加之后的普通候选抽取。因此管理员并不是仅持续一层的三选一增益；随着楼层推进，多名管理员的愚见可能共同作用。

## 愚见

「愚见」是管理员理解世界的错误前提。管理员把自己的偏见当成事实，而世界随后会依照这个前提重新解释局部规则。

例如，当前已实装的该隐会把钥匙与免费资源联系起来：Zeiz 一方拥有至少 {{Key}} 3 把钥匙时，一部分符合条件的免费掉落物有 40% 概率被加锁，取得它们还需再支付 1 把钥匙。

因此愚见的重点不是简单的正负数值，而是改变什么资源重要、什么行为危险，以及原本普通的选择应该怎样重新判断。

## 兴趣

每位管理员都会关注不同种类的事件。相关事件发生时会积累兴趣；同一房间内连续重复同类事件的收益会逐次减半，避免依靠无限重复单一动作迅速刷满。

| 兴趣 | 状态 |
| ---: | --- |
| 0～2 | 正常 |
| 3～4 | 感兴趣 |
| 5 | 提案准备完成 |

每名管理员每层通过事件最多获得 8 点兴趣。达到提案状态后，它不会继续通过普通事件增长，直到提案状态被处理。

## 提案

提案代表管理员对玩家持续引起其兴趣后的回应。当前底层已经支持准备提案、接受或拒绝，以及在接受时发放管理员关联的内容。

不过，当前玩家侧尚无完整的提案决策界面，且多名管理员的提案内容仍是占位。因此“提案”目前应理解为已经接入状态与扩展框架、但尚未完整开放的系统层，而不是稳定可用的常规奖励流程。

## 元管理员

「元管理员」是一名特殊管理员。普通愚见作用于游戏世界，而它的长期定位是进一步干涉管理员、愚见、提案和控制中枢本身。

当前实现已经注册元管理员及其专用兴趣类型，但它被设置为非普通候选，不会出现在常规候选中；完整玩法尚未开放。

## 当前实现状态

控制中枢的房间入口、管理员登记、候选抽取、任命、愚见分发、兴趣和提案状态等基础框架已经存在。当前登记的管理员包括该隐、店长、???、伯大尼、伊甸和元管理员，但只有该隐具有完整可见的愚见效果，其他内容仍在逐步完成。
