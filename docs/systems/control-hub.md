# 控制中枢

「控制中枢」是 {{Character:zeiz}} 任命管理员的专属房间。每名管理员的「愚见」会持续修改本局中的特定规则。

> 任命管理员 → 愚见生效 → 行为引起兴趣 → 提案准备

## 管理员

每次需要进行新任命时，系统会从尚未任命、并且允许作为候选的管理员中随机选出至多三名。

任命后的管理员会保留在本局列表中，不再参加之后的普通候选抽取。多名已任命管理员的愚见可以同时生效。

## 愚见

「愚见」不是管理员刻意设计的增益或惩罚，而是管理员确信为真的片面解释。任命后，这种解释会成为实际生效的规则。

例如，当前已实装的该隐会把钥匙与免费资源联系起来：Zeiz 一方拥有至少 {{Key}} 3 把钥匙时，一部分符合条件的免费掉落物有 40% 概率被加锁，取得它们还需再支付 1 把钥匙。

## 兴趣

每位管理员都会关注不同种类的事件。相关事件发生时会积累兴趣，表示管理员认为世界正在验证自己的判断；同一房间内连续重复同类事件的收益会逐次减半，避免依靠无限重复单一动作迅速刷满。

| 兴趣 | 状态 |
| ---: | --- |
| 0～2 | 正常 |
| 3～4 | 感兴趣 |
| 5 | 提案准备完成 |

每名管理员每层通过事件最多获得 8 点兴趣。达到提案状态后，它不会继续通过普通事件增长，直到提案状态被处理。

## 提案

兴趣达到 5 点时，管理员进入提案准备状态，并停止通过普通事件继续增长兴趣。提案意味着管理员试图把自己的愚见进一步扩张到其他规则；当前版本中，提案决策尚未对玩家开放。

## 元管理员

「元管理员」是特殊管理员，其愚见指向管理员、愚见或控制中枢本身，而不是单独的游戏资源。元管理员不会出现在普通候选中，当前版本尚未开放其任命方式。

普通候选包括该隐、店长、???、伯大尼和伊甸。只有页面中显示具体愚见的管理员会提供对应规则效果。
