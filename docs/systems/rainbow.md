# 彩虹

「彩虹」是 Glaze Ceremony 中一种特殊的视觉与设计分类。这些道具通常围绕特定的精神疾病、精神状态或认知体验展开，也常作为模组角色击败精神错乱后的解锁奖励。

彩虹道具目前**没有统一的套装效果或共同战斗机制**。这个名称首先描述它们的视觉主题、设计联系与常见解锁来源；具体效果和解锁条件仍以各道具页面为准。

## 视觉语言

许多彩虹道具会从一个含义相近的原版道具出发，重新绘制为彩虹色版本。两者可能共享某种意象或玩法联想，但彩虹道具并不因此继承原版道具的效果。

## 获取

彩虹道具通常是模组角色击败精神错乱后的解锁奖励，但这不是每一件彩虹道具都必须遵守的规则。准确的解锁条件会显示在对应道具的资料卡中。

## 未来方向

::: warning 尚未实装
彩虹道具未来可能发展出更明确的系列或套装联系。当前版本没有据此提供额外加成，也不应把同时持有多件彩虹道具理解为已经形成套装。
:::
