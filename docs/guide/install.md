# 安装与要求

## 当前版本

当前公开版本为 **alpha-0.1**，属于重制工程的公开测试版本。

正常剧情目前只开放到序章结束。第一章「所求之物」仍在开发中。

## 游戏要求

建议使用当前受 REPENTOGON 支持的《The Binding of Isaac: Repentance+》版本。

本模组的完整功能需要 **REPENTOGON**。缺少 REPENTOGON 时，部分功能可能无法工作，或只能以有限兼容模式加载。

## 下载

当前 Alpha 测试版本从公开 GitHub Release 获取：

https://github.com/LoremnMeus/-TBOI-Glaze_Ceremony-RGON-/releases

玩家 Wiki：

https://loremnmeus.github.io/-TBOI-Glaze_Ceremony-Wiki-/

## 手动安装

下载发布包后，将其中的：

`Qing_remaster`

文件夹放入 Isaac 的 `mods` 目录。

最终结构应类似：

`mods/Qing_remaster/main.lua`

不要额外再套一层压缩包目录。

## 更新版本

更新测试版本时，建议先退出游戏，再用新版本完整替换旧的 `Qing_remaster` 文件夹。

不要将旧版开发文件、旧版琉璃圣典文件和当前重制版目录混合覆盖。

## 出现问题时

首先确认：

- 游戏版本是否符合当前 REPENTOGON 要求；
- REPENTOGON 是否正确加载；
- 模组是否安装在正确目录；
- 是否存在旧版本文件残留；
- 是否有其他模组影响相同机制。

已知的启动黑屏问题见：

[进入后黑屏](/troubleshooting/black-screen)

其他 Bug 或兼容性问题请提交到：

https://github.com/LoremnMeus/-TBOI-Glaze_Ceremony-RGON-/issues

如果发生崩溃，请尽量同时附上对应的日志与 `.dmp` 文件。
