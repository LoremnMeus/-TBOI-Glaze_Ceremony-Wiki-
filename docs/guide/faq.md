# 常见问题

## 为什么完成序章后没有第一章？

这是当前版本的正常行为。

`alpha-0.1` 的正式剧情范围只开放到序章结束。第一章「所求之物」仍在开发，因此不会在当前 Alpha 的正常流程中开始。

## 这个版本已经是完整重制版了吗？

不是。

当前版本仍属于 Alpha 测试阶段。道具、卡牌、剧情、角色兼容、界面和其他系统已经完成了大量重构，但整个重制工程仍在继续。

## 所有角色都已经完成重制了吗？

没有。

不同角色目前处于不同阶段。有些角色主要剩余细节调整，另一些角色仍有较大的兼容或表现工作需要完成。

里小青目前只完成了较基础的原版道具兼容，飞行器皮肤和本模组自定义道具兼容仍未完成。

## 为什么 Wiki 中有些内容比游戏开发进度更慢？

Wiki 只应公开已经能够根据当前代码和实际玩法确认的内容。

开发中的机制不会因为代码文件已经存在就自动视为玩家可用内容。部分页面会在核验后逐步补全。

## 什么时候重新发布 Steam Workshop？

当前没有承诺具体日期。

计划是在第一章、角色重制精调以及其他主要内容达到正式发布标准后重新发布到 Steam Workshop。

在此之前，GitHub 公开版本是主要 Alpha 测试渠道。

## 在哪里报告 Bug？

请使用公开仓库的 GitHub Issues：

https://github.com/LoremnMeus/-TBOI-Glaze_Ceremony-RGON-/issues

这里也是当前开发阶段主要的公开反馈渠道。

## 游戏崩溃时应该提供什么？

请尽量提供：

- 模组版本；
- Isaac 游戏版本；
- REPENTOGON 版本；
- 当时使用的角色；
- 所在楼层或房间；
- 崩溃前正在进行的操作；
- 其他启用的模组；
- 相关日志；
- 对应的 `.dmp` 崩溃转储文件。

如果无法判断具体是哪份日志，可以附上崩溃时间附近生成的文件。
