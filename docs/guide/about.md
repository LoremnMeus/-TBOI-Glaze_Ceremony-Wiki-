# 模组介绍

**《琉璃盛典：应许之地》** 是《The Binding of Isaac: Repentance+》内容模组《琉璃圣典》的重制与继续开发版本。

当前公开版本仍处于 **Alpha 测试阶段**。本阶段的重点是重新整理旧版内容、修复长期遗留问题，并逐步建立新的剧情、角色兼容、界面和公共机制。部分内容已经完成较大幅度重构，另一些内容仍会继续修改。

## alpha-0.1 包含什么

当前版本包含原版《琉璃圣典》已有的道具与卡牌内容，以及目前已经完成的机制重构、修复和新增内容。

剧情方面，`alpha-0.1` 正式开放完整的**序章**流程。

第一章 **「所求之物」** 及其后续剧情仍在开发中，因此不会在当前版本的正常游玩流程中开放。

## 角色状态

角色重制与兼容工作仍在持续进行，不同角色目前处于不同的完成阶段。

部分角色主要剩余数值、操作体验、表现或兼容性方面的细节调整；这并不意味着所有角色已经完成最终重制。

**里小青**目前已经完成较基础的原版道具兼容，但仍缺少两块重要工作：

- 飞行器皮肤及相关视觉适配；
- 本模组自定义道具与机制的完整兼容。

因此，Alpha 阶段角色机制、数值、兼容性和表现仍可能继续变化。

## 当前发布方式

目前 GitHub 公开版本是主要的 Alpha 测试渠道。

第一章、角色兼容与精调，以及其他主要重制内容达到正式发布标准后，模组计划重新发布至 Steam Workshop。

在此之前，请将公开版本视为仍在开发中的测试版本。
