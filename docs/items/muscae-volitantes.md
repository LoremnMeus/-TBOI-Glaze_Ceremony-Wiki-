## 效果

**飞蚊症召来一群彩色飞蚊，随机留下彩虹苍蝇、饰品或道具。**

| 概率 | 结果 |
| ---: | --- |
| 66% | 留下 **2–3** 只彩虹苍蝇 |
| 33% | 留下随机饰品 |
| 1% | 留下随机道具 |

### {{Collectible:34}}

### {{Collectible:584}}
