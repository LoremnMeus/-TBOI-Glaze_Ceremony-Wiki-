## 效果

**飞蚊症是一台很直白的三档抽奖机：大多数时候留下几只彩虹苍蝇，偶尔给饰品，极少数时候直接吐出一个道具。**

使用后先出现彩色飞蚊聚集（约 **40** 帧），再开奖：

| 概率 | 结果 |
| ---: | --- |
| 66% | 留下 **2–3** 只彩虹苍蝇 |
| 33% | 留下随机饰品 |
| 1% | 留下随机道具 |

## 特殊联动

### {{Collectible:34}}

苍蝇奖励改为战争蝗虫；聚集过程中的飞蚊还可伤害路径上的敌人。

### {{Collectible:584}}

苍蝇奖励改为彩虹魂火。
