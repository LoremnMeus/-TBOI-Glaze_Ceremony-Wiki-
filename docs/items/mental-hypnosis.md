## 效果

精神控制把每层的特殊房间变成一条必须按顺序完成的访问路线。

每层开始时，根据本层存在的特殊房间生成一串随机的**房间指令**，并在 HUD 上显示尚未完成的顺序。

之后，每当玩家**首次进入**一个参与判定的特殊房间时：

- 如果房间类型与当前指令一致，立即获得一次随机奖励；
- 如果进入了其他特殊房间，立即受到一次随机惩罚。

无论成功还是失败，当前指令都会结束，并继续检查下一条。

**普通房间不计入指令；只有首次进入需要计数的特殊房间时才进行判定。**

例如，若指令为「宝物房 → 商店 → Boss 房」，途中经过普通房不会影响进度；若第二条要求商店却先进入诅咒房，则当前一条失败并受到惩罚，之后继续下一条，整串指令不会重置。

## 奖励

每完成一条正确指令，都会随机获得一次奖励。

正确执行可能随机获得持续到**本局结束**的属性提升，或生成硬币、炸弹、钥匙、电池、红心、卡牌、药丸、友军等；极少情况下会直接生成一件道具。多次成功可以叠加这些收益。

## 惩罚

错误进入特殊房间时，会随机受到一次惩罚。

错误执行可能随机降低属性、损失资源，或生成搞笑炸弹等危险掉落。这些变化同样持续到本局结束；一次失误只会让当前这一条结算惩罚，不会让本层之前的进度全部作废。

## 注意

- 只在**首次进入**参与判定的房间时检查指令；重新进入已经访问过的房间不会再次结算。
- 指令以**房间类型**判断，而不是指定地图上的某一个具体房间；如果一层存在多个同类型特殊房间，进入符合当前要求的任意一个都可以完成该条指令。
- 奖励与惩罚中的属性变化会持续到本局结束，并可以相互叠加。
- 每次进入新层都会重新生成该层的指令表。

## 轶事

「精神控制」的设计围绕「遵循外部指令」这一主题展开：机制上，特殊房间被组织成必须按顺序完成的指令路线。

贴图以 {{Collectible:13}} 等针套道具为原型重新绘制；针套自带的注射、灌输意象，与这套「按指令执行」的玩法相互呼应。

<summary>技术细节</summary>

- 每层开始时，根据本层存在的特殊房间生成一串随机房间类型指令。
- 普通房间以及若干不适合作为指令目标的房间类型会被排除。
- 指令按房间类型匹配；同类型多个房间任进其一即可。
- 每个参与判定的房间只在首次进入时结算；成功或失败都会推进到下一条指令。
- 属性奖励与属性惩罚持续到本局结束，换层不会清除。
- 部分特殊位置的隐藏房不会被排成明显无法合理完成的顺序。
- 贪婪模式对部分特殊房间的排列也有额外处理。

### 奖励与惩罚明细

**奖励属性（可叠加）**

| 类型 | 效果 |
| --- | --- |
| 攻击 | +0.5 |
| 射速 | +0.35 |
| 弹速 | +0.15 |
| 射程 | +1 |
| 移速 | +0.15 |
| 幸运 | +1 |
| 体型 | ×0.9 |

**奖励掉落**

- 1～5 枚硬币、1～2 颗炸弹或钥匙、1～2 节电池、2～4 颗红心；
- 卡牌、药丸；
- 蓝蜘蛛、蓝苍蝇；
- 漂亮苍蝇、友方粪滴；
- 极少情况下直接生成一件道具。

**惩罚属性（可叠加）**

| 类型 | 效果 |
| --- | --- |
| 攻击 | −0.2 |
| 射速 | −0.2 |
| 弹速 | −0.1 |
| 射程 | −0.5 |
| 移速 | −0.1 |
| 幸运 | −0.5 |
| 体型 | ×1.12 |

**惩罚效果**

- 失去 10 枚硬币、3 颗炸弹或钥匙，或失去金钥匙、金炸弹；
- 失去 1 枚硬币并额外 −1 幸运；
- 生成搞笑炸弹、巨型搞笑炸弹、金搞笑炸弹等危险掉落。
