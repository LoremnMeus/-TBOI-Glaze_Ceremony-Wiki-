## 效果

每层开始时，精神控制会根据本层存在的特殊房间生成一串随机的**房间指令**，并在 HUD 上显示尚未完成的顺序。

之后，每当玩家**首次进入**一个参与判定的特殊房间时：

- 如果房间类型与当前指令一致，立即获得一次随机奖励；
- 如果进入了其他特殊房间，立即受到一次随机惩罚。

无论成功还是失败，当前指令都会结束，并继续检查下一条。

因此，精神控制要求的并不是「把所有指定房间找出来」，而是**按照给出的顺序安排本层特殊房间的访问路线**。

**普通房间不计入指令；只有首次进入需要计数的特殊房间时才进行判定。**

## 如何执行指令

普通房间不会参与判定。

例如当前指令为：

> 宝物房 → 商店 → Boss 房

你可以在这些房间之间正常经过任意数量的普通战斗房。

只要首次进入的特殊房间依次是宝物房、商店和 Boss 房，就可以连续获得奖励。

但如果第二条要求商店，而你提前进入了诅咒房：

> 宝物房 ✓
> 诅咒房 ✗
> 下一条指令继续

这次错误会立即受到一次惩罚，但**不会重置整串指令**。

## 奖励

每完成一条正确指令，都会随机获得一次奖励。

可能获得：

| 类型 | 效果 |
| --- | --- |
| 攻击 | +0.5 |
| 射速 | +0.35 |
| 弹速 | +0.15 |
| 射程 | +40 |
| 移速 | +0.15 |
| 幸运 | +1 |
| 体型 | ×0.9 |

也可能立即生成资源或友军：

- 1～5 枚硬币、1～2 颗炸弹或钥匙、1～2 节电池、2～4 颗红心；
- 卡牌、药丸；
- 蓝蜘蛛、蓝苍蝇；
- 漂亮苍蝇、友方粪滴；
- 极少情况下直接生成一件道具。

属性类奖励属于[本局永久](/systems/permanent-effects)效果，可以通过多次正确执行指令不断累积。

## 惩罚

错误进入特殊房间时，会随机受到一次惩罚。

可能包括：

| 类型 | 效果 |
| --- | --- |
| 攻击 | −0.2 |
| 射速 | −0.2 |
| 弹速 | −0.1 |
| 射程 | −20 |
| 移速 | −0.1 |
| 幸运 | −0.5 |
| 体型 | ×1.12 |

也可能损失硬币、炸弹或钥匙，失去金钥匙或金炸弹，或生成搞笑炸弹、巨型搞笑炸弹、金搞笑炸弹等危险掉落。

属性类惩罚同样属于本局永久效果。惩罚结束后仍然会进入下一条指令，因此一次失误不会让本层之前的进度全部作废。

## 注意

- 只在**首次进入**参与判定的房间时检查指令；重新进入已经访问过的房间不会再次结算。
- 普通房间不会推进指令，也不会因为「走错普通房」受到惩罚。
- 指令以**房间类型**判断，而不是指定地图上的某一个具体房间；如果一层存在多个同类型特殊房间，进入符合当前要求的任意一个都可以完成该条指令。
- 奖励与惩罚中的属性变化会持续到本局结束，并可以相互叠加。
- 每次进入新层都会重新生成该层的指令表。

## 使用技巧

先观察 HUD 上最前面的几条指令，再决定本层探索路线。

精神控制并不要求你完全按照地图的自然探索顺序前进。某些情况下，为了先进入正确的特殊房间，绕路、暂时跳过已经发现的房间，甚至延后进入 Boss 房都会更有价值。

已经发现但顺序尚未轮到的特殊房间可以先留着，等对应图标移动到指令首位后再进入。

如果当前路线使某条指令很难完成，也不一定需要彻底放弃这一层：走错只会结算当前这一条的惩罚，之后仍然可以继续争取剩余指令的奖励。

<details>
<summary>技术细节</summary>

- 每层开始时扫描本层可参与机制的房间，并随机排列其房间类型。
- 普通房间以及若干不适合作为指令目标的房间类型会被排除。
- 指令按房间类型匹配，而非具体 RoomDescriptor。
- 每个参与判定的房间只在首次进入时结算。
- 正确与错误都会将当前指令索引推进 1。
- 属性奖励与属性惩罚均保存在本局状态中，不会在进入下一层时清除。
- REPENTOGON 环境下，对部分位置特殊的隐藏房生成顺序进行了额外处理，避免生成明显不合理的访问顺序。
- 贪婪模式对部分特殊房间的排列也有额外处理。

</details>
