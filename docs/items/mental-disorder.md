## 效果

**精神失序会让玩家偶尔把某样东西误认为存在第二份。**

进入新房间时有 **25%** 概率产生一个“错误事实”，可能涉及掉落物、敌人或玩家已有的道具效果。

| 错认对象 | 会发生什么 | 如何结束 |
| --- | --- | --- |
| 掉落物 | 多出一份可正常拾取的掉落物 | 离房时追回仍未消费的虚假资源 |
| 敌人 | 多出一个能够行动和攻击的敌人 | 受到真实伤害后立即消失 |
| 已有道具 | 暂时获得第二份已有道具效果 | 离房时移除 |

错误掉落物获得的资源可以正常消费；已经用掉的部分不会在离房时被追回。普通硬币、钥匙、炸弹、心、电池、卡牌和药丸等都可能成为错误事实；部分具有特殊永久性质或容易产生异常收益的掉落不会被复制。对卡牌和药丸而言，只要在离开房间前真正使用，已经发动的效果就会保留。

::: tip 花掉假的，也能买到真的
如果错误事实让你多获得了 3 枚硬币，并在离房前花掉其中 2 枚，那么已经完成的购买不会被撤销。离开房间时，只会尝试追回仍然存在的虚假部分。
:::

错误敌人不会锁住房门，也不会提供正常击杀奖励；受到一次真实伤害即被识破并消失。Boss 和精英敌人不会成为这种错误事实。

错误道具只会临时复制玩家已经拥有、且允许临时复制的被动或跟班效果，不会凭空给予原本没有的随机道具。部分不能安全临时复制的特殊道具不会参与这种错认。

## 注意

- 同时只能存在一个错误事实。
- 当前没有合法候选的类别不会参与抽取。
- 离开房间后，当前错误事实会结束。虚假资源只追回仍未消费的部分。
- 错误出现时会伴随短暂画面失真；部分真实实体也可能出现类似视觉异常，因此不能仅凭 glitch 判断真假。

## 轶事

精神失序属于[彩虹](/systems/rainbow)道具，贴图以 {{Collectible:402}} 为原型重新绘制。

混沌打乱道具池原本的秩序，而精神失序则扰乱玩家对当前房间“事实”的认知；两者都围绕“失序”展开。

### 触发与类型权重

进入房间后基础触发率为 **25%**。

当三类错误均有合法候选时，基础选择权重为：

| 类型 | 权重 |
| --- | ---: |
| 掉落物 | 50 |
| 敌人 | 35 |
| 已有道具 | 15 |

如果某类不存在合法候选，则不会参与随机，因此这些权重并不等同于始终固定的 50% / 35% / 15% 出现概率。

### 候选限制

错误掉落物只会从当前房间符合条件的免费普通掉落中选择；商店商品和部分特殊掉落会被排除。

错误敌人不会选择 Boss、精英敌人以及部分特殊实体。

错误道具只会从玩家当前已经持有、且能够安全临时复制的被动或跟班道具中选择；复活、物品栏扩展、任务物品和部分特殊状态型道具会被排除。

</details>
