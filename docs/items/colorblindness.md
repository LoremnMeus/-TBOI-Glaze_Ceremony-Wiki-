## 机制说明

## 效果

傲慢或是偏见允许你直接评价地上的道具。评价不会改变眼前这件道具，而会改变它之后在道具池中的命运。

靠近一个可评价的道具底座时，会出现操作提示。

## 如何评价

| 操作 | 键鼠       | 手柄          |
| -- | -------- | ----------- |
| 点赞 | Ctrl + E | Drop + 向右攻击 |
| 点踩 | Ctrl + Q | Drop + 向左攻击 |

## 评价结果

| 评价    | 效果                          |
| ----- | --------------------------- |
| 👍 点赞 | 向该道具所在的当前道具池额外加入一份该道具，本局有效  |
| 👎 点踩 | 将该道具从本局道具池排除，并在下一次新开局继续排除一次 |

## 注意

* 评价不会复制或删除眼前的实体底座。
* 同一个底座只能评价一次。
* 无法看见内容的盲目底座不能评价。
* 点踩产生的“下一局排除”只会生效一次；下一次新开局应用后便会清除。
* 继续当前存档不会提前消耗下一局的排除效果。

## 使用技巧

可以点踩一件当前仍然想拿的道具，再拾取眼前这一份：本次仍能获得它，同时阻止它在本局后续再次出现，并让它在下一局继续缺席一次。
