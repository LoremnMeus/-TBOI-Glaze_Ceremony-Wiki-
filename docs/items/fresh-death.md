## 效果

**每份鲜活死者都保存 3 件随机被动的效果。**

这些效果不会作为真实道具进入物品栏，而是由鲜活死者内部记录，并在临时道具 HUD 中显示。EID 查看鲜活死者时，也能看到当前实际获得的道具图标。

每多持有一份，就再独立保存另外 3 件效果。

## 从哪里来

鲜活死者主要由 {{Item:the-suture-needle}} 把房间里的道具底座转化而来。

完整转化代价与房间规则见该页，不要在本页重复整套新式缝合针玩法。

## 注意

- 与 {{Item:suture-needle}}（普通缝合针）无关；那是另一件主动道具。
- 彼列书 / 美德书会影响新式缝合针生成鲜活死者时抽取的道具池，见 {{Item:the-suture-needle}}。
