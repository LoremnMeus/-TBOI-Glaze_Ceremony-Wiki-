## 效果

真实之名是一场关于「道具池下一抽」的猜谜。

使用后打开完整道具选择界面，先从全部道具中选出你认为**下一次会抽到**的那一件；随后系统真正执行一次抽取，并与你的猜测比较。

## 猜中

若结果相同：生成猜中的道具，并额外生成 {{Collectible:628}} 死亡证明。

## 猜错

若结果不同：本次预测失败，不会获得大奖（会揭示真实抽取结果作为失败反馈）。

## 为什么值得猜

这不是随机三选一，而是对「当前道具池下一抽」的预测。可以利用已取出道具、池状态与知识进行猜测；精确命中极难，大奖也因此夸张。

## 特殊联动

### {{Collectible:34}}

### {{Collectible:584}}

猜中后生成对应道具的魂火。

## 轶事

- 指向《游戏王》的同名卡「真实之名」。
- 原卡与本道具都围绕「正确猜中指定内容后获得奖励」展开；在以撒中无法像卡牌游戏那样方便地预先安排结果，因此更难主动作弊。
