## 机制说明

## 效果

**透特之书是一册会随着冒险逐渐补全、并把见过的牌面变成可反复调用法术的卡册。**

它会记录玩家在本局中见过的透特牌。收集不同牌面获得启示，再消耗启示从已记录的牌中组成牌阵，使它们在之后的战斗房中自动发动。

## 如何使用

### 1. 收录牌面

持有透特之书期间，第一次获得并持有某种透特牌时，对应牌面会被收录进卡册。正位和逆位分别记录；收录不会消耗卡牌，之后使用或丢弃它也不会抹去记录。

::: tip 补全卡册
持有透特之书时，游戏会更倾向于从卡池生成尚未收录的透特牌，并可能把部分普通塔罗牌替换成透特牌。卡册会随着流程自然补全。
:::

### 2. 获得启示

启示是透特之书进行占卜所需的资源。首次获得书、收录新牌面以及玩家亲自使用透特牌都能提供启示；清理房间和普通电池不能为它恢复启示。

### 3. 进行占卜

使用透特之书会打开专属界面。“卡册”用于查看牌面的收录状态；“占卜”用于从本层仍可使用的牌面中选择牌阵。

一次占卜固定消耗 3 点启示，可以选择 1～3 张不同牌面。选择数量不会改变费用，选择的先后也不决定发动顺序。

### 4. 发动牌阵

牌阵建立后，每次进入一个新的未清理战斗房，都会从尚未发动的牌中随机选择一张并免费使用。所有牌都发动后，本次牌阵结束，之后才能再次占卜。

牌阵尚未完成时仍可打开卡册查看记录，但不能覆盖当前牌阵。同一牌面每层最多由透特之书成功发动一次。

## 操作与界面

### 卡册页

- 正常显示的牌面已经收录，可以用于之后的占卜。
- `???` 或“尚未收录”表示该牌面仍未进入卡册。
- “本层已解读”表示该牌本层已经由透特之书发动，暂时不能再次选择。

### 占卜页与当前牌阵

占卜页显示当前启示、可用牌面和已经选入的牌。牌阵开始后，主动道具栏与界面会区分已经翻开的牌和仍在等待的牌；等待中的牌不会提前透露本次随机发动顺序。

## 启示

| 行为 | 启示变化 |
| --- | ---: |
| 首次获得透特之书 | 设为 3 |
| 首次收录一个新牌面 | +1 |
| 玩家亲自使用一张透特牌 | +2 |
| 进行一次占卜 | −3 |
| 最大启示 | 12 |

由牌阵免费发动的透特牌不会再次提供启示。失去透特之书后再取回时，卡册与原有启示仍会保留，也不会重复获得初始 3 点。

## 牌阵规则

- 一次占卜固定消耗 3 点启示。
- 默认最多选择 3 张不同的可用牌面。
- 每进入一个新的未清理战斗房，随机发动一张尚未使用的牌。
- 同一牌面每层只能由透特之书发动一次；正位与逆位分别计算。
- 当前牌阵必须全部发动后才能建立新牌阵。
- 未完成的牌阵可以带入下一层。
- 进入新楼层后，本层已发动牌面的限制与房间触发记录重置。

## 特殊联动

- {{Collectible34}} **彼列书：** 牌阵容量由 3 张提高到 4 张，建立牌阵仍只消耗 3 点启示。四张牌遵守相同的随机发动和每层限用规则。
- {{Seija}}：地面上的透特牌只显示未知牌面。新收录的牌会先以“未揭示”状态进入卡册，照常提供启示且可以选入占卜；第一次成功建立牌阵时，这些记录才会一并翻开。离开正邪状态也会揭示仍在等待的记录。
- {{Collectible584}} **美德之书：** 透特之书生成的魂火熄灭时会掉落一张塔罗牌。
- {{Collectible:706}} **深渊：** 对应蝗虫命中敌人后有概率生成卡牌。

## 细节与特殊情况

- Boss 房、小 Boss 房、挑战房和 Boss Rush 都可以推进牌阵；普通隐藏房、诅咒房和献祭房不会仅因存在敌人而触发。
- 在已经进入且尚未清理的战斗房中现场建立牌阵，不会立刻在当前房间发动。
- 同一个房间只会推进一次。离开后重新进入不会再次发动牌面。
- 自动发动仍会调用卡牌的正常使用流程，但会屏蔽播报动画，并阻止这次使用再次提供启示。
- 卡册与启示按玩家分别保存；判断哪些牌面尚未见过并据此调整卡池时，则会综合本局所有持书玩家的收录情况。

## 轶事

“透特之书”的名字来自 Aleister Crowley 于 1944 年首次出版的 [*The Book of Thoth*](https://academic.oup.com/book/58979)。该书系统说明了 Crowley 与艺术家 Lady Frieda Harris 合作完成的 Thoth Tarot；[Oxford University Press 对二人合作的研究](https://academic.oup.com/book/58979/chapter-abstract/494473299)也特别讨论了 Harris 对牌面创作的贡献。

模组把“书与牌”的关系改写成一局内的收集过程：玩家并非打开一本已经写完的牌典，而是把自己实际见过的正位与逆位牌面逐步写回书中，再从这些记录里进行占卜。

### 卡池倾向

在透特牌候选中，已收录牌面的基础权重为 **1**，未收录牌面的基础权重为 **3**。这是候选权重，不代表未收录牌具有固定 75% 的出现概率。

当卡池原本抽到普通塔罗牌时，替换概率为“当前未收录透特牌面数 ÷ 当前可生成透特牌面总数”，上限为 **50%**；随后再按上述权重选择具体牌面。由实体直接生成或玩家放下的卡牌不经过这次卡池改抽。

### 数据边界

卡册、启示、牌阵、本层已发动记录和房间防重复记录均按玩家保存。获得卡牌的登记点是卡牌进入玩家卡牌栏，而不是卡牌实体出现在房间中。
