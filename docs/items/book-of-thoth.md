## 机制说明

### 概览

{{Item:book-of-thoth}} 会把你在本局见过的 {{System:thoth-cards}} 逐渐收录成一副属于自己的卡册。

获得新的牌面和亲自使用透特牌可以积累「启示」。消耗启示后，你可以从卡册中挑选数张牌组成牌阵；之后进入新的战斗房时，牌阵中的一张牌会被随机揭示并免费发动。

因此，透特之书并不是单纯复制手里的卡牌，而是把一路收集过的牌面逐渐变成可以重复调用的长期资源。

### 玩法

#### 收录牌面

持有透特之书时，第一次获得某张透特牌的牌面，会将它登记进卡册并获得 1 点启示。正位与逆位视为不同牌面，分别登记；登记过的牌不会因为使用或丢弃而从卡册中消失。

#### 积累启示

首次获得透特之书时拥有 3 点启示。

| 行为 | 启示 |
| --- | ---: |
| 首次登记一个牌面 | +1 |
| 玩家亲自使用一张透特牌 | +2 |
| 组成一次牌阵 | -3 |
| 上限 | 12 |

启示不会通过清理房间或普通电池自然恢复。

#### 组成牌阵

使用透特之书会打开卡册。支付 3 点启示后，可以从已经登记、且本层仍可解读的牌面中选择 1～3 张组成牌阵。

选择数量不会改变消耗：选 1 张和选 3 张都需要 3 点启示。牌阵也不会预先决定发动顺序。

#### 发动牌阵

组成牌阵后，每当进入一个新的、尚未清理的战斗房，会从仍未发动的牌中随机选择一张免费发动。同一个房间不会重复推进牌阵。

牌阵中的牌全部发动后，本次占卜结束，可以再次组成新的牌阵。

### 示例

假设卡册已经记录「太阳·正位」「死神·逆位」和「星星·正位」，并花费 3 点启示将它们全部加入牌阵。

进入第一个新战斗房时，可能先发动「星星」；进入下一个战斗房时，再从剩余两张中随机发动一张。

- 只选择一张：可以确定下一次会发动什么。
- 选择三张：启示利用率最高，但牺牲发动顺序的确定性。

### 详细规则

- 已经由透特之书成功发动过的牌面，本层不能再次加入新的牌阵；正位与逆位分别计算。
- 当前牌阵还没有全部发动时，可以查看卡册，但不能用新的牌阵覆盖它。
- 在未清理的战斗房中组成牌阵时，不会立即触发当前房间。
- {{BossRoom}} Boss 房、小 Boss 房、挑战房和 Boss Rush 均可推进牌阵。
- 未完成的牌阵可以跨层保留；进入新楼层后，本层的牌面使用限制与房间触发记录会重新计算。
- 由透特之书免费发动的牌不会再次提供启示。
- 持有本书时，会提高尚未登记透特牌面的出现机会，并使普通塔罗牌有机会替换为透特牌。具体生成规则见 {{System:thoth-cards}}。

### 使用技巧

如果需要某张牌服务于下一场关键战斗，只放入 1 张可以换取完全确定的结果。如果并不在意发动顺序，尽量组成 3 张牌阵通常最划算，因为消耗始终是 3 点启示。

透特之书的价值也与获得时间有关：越早拿到，就有越多机会扩充卡册并积累启示。
