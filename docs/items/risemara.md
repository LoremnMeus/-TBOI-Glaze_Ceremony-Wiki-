## 效果

勇者祝福把「重置马拉松」塞进了一件道具里。拾取时会为六项基础属性分别随机评级；不满意就把它放回原来的底座，再捡一次，直到骰出愿意接受的角色。

覆盖属性：攻击、射速、射程、移速、幸运、弹速。每项都可能是正面、中性或负面，拾取时会立刻显示本次评级。

## 评级

每项评级对应最大幅度的倍率：

| 等级 | 倍率 |
| --- | ---: |
| 高正面 | +100% |
| 中正面 | +2/3 |
| 小正面 | +1/3 |
| 中性 | 0 |
| 小负面 | −1/3 |
| 中负面 | −2/3 |
| 大负面 | −100% |

各属性的最大正/负幅度：

| 属性 | 最大幅度 |
| --- | ---: |
| 攻击 | ±3 |
| 射速 | ±1.5 |
| 射程 | ±4.5 |
| 移速 | ±0.6 |
| 幸运 | ±6 |
| 弹速 | ±0.6 |

## 重刷

拾取后会记住原本的空底座。靠近该底座时角色会举起勇者祝福；接触后将其放回，再次拾取会重新生成全部六项评级。上一组结果不会保留，可以反复放回并重新拾取，没有次数限制。

## 注意

- 评级是整组重抽，不能只保留某一项。

## 轶事

“勇者祝福”影射《游戏王》「阿拉弥赛亚之仪」及其勇者主题，同时将常见的「重置马拉松」——不断重开直到随机到理想初始属性——直接做成了本道具的玩法。
