## 机制说明

## 效果

**缝合针把两个敌人的不同部分组合成新的友军：一边负责怎么移动，另一边负责怎么攻击。**

使用后可以分别挑选一个**移动部件**和一个**攻击部件**。完成选择后，两者会组成一只缝合体；移动部件决定它的移动方式，攻击部件决定它的攻击方式。

生成的缝合体会跟随角色进入其他房间，直到自身被消灭。再次使用缝合针可以继续生成新的缝合体，已有缝合体不会因此被替换。

## 如何使用

选择界面左侧为移动部件，右侧为攻击部件，中间显示组合预览。

- 使用射击方向移动光标；
- 按主动道具键锁定当前部件；
- 两种部件都锁定后，在中央确认组合；
- 按丢弃键可以取消选择。

只有成功生成缝合体后才会消耗充能。取消选择，或在选择期间离开房间，都不会消耗充能。

## 可选部件

| 种类 | 敌人 | 主要行为 |
| --- | --- | --- |
| 移动 | Gaper | 追逐目标 |
| 移动 | Charger | 冲刺移动 |
| 移动 | Globin | 游荡，并保留其再生相关行为 |
| 攻击 | Horf | 发射单颗弹幕 |
| 攻击 | Pooter | 飞行并发射弹幕 |
| 攻击 | Host | 使用 Host 的攻击方式 |

移动部件和攻击部件可以任意搭配。

## 注意

- 只有列入选择界面的敌人可以作为部件。
- 缝合体取用的是两个部件各自负责的行为，并不会同时获得两个敌人的全部能力。
