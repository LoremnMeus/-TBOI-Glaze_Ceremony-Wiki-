## 效果

没有命中目标的眼泪会短暂停顿，然后重新寻找附近的敌人。这不是持续追踪：眼泪只有在偏离目标后才会重新选择方向。

每枚眼泪最多重新求索 3 次，并在每次求索后提高伤害：

| 求索次数 | 伤害倍率 |
| ---: | ---: |
| 0 | 100% |
| 1 | 115% |
| 2 | 130% |
| 3 | 150% |
