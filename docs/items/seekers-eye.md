## 效果

**求索者之眼让眼泪在偏航、擦过或撞墙卡住时停下来重新找路，而不是只会普通追踪。**

普通追踪泪会朝目标拐弯；求索则会在必要时短暂停顿，再重新锁定附近敌人，必要时绕过障碍。

每枚眼泪最多重新求索 **3** 次。每次成功重新求索后伤害提高：

| 已求索次数 | 伤害倍率 |
| ---: | ---: |
| 0 | ×1.00 |
| 1 | ×1.15 |
| 2 | ×1.30 |
| 3 | ×1.50 |

求索时如何绕路：

- 直线通畅时直接飞向目标。
- 被阻挡时尝试寻找绕行路径。
- 灵体泪不会因为求索失去穿墙能力。
- 如果无法找到路线，可能沿墙滑动；仍无法脱离时结束本次求索。

## 注意

鲁多维科与部分环绕类泪弹不会参与求索。
