## 效果

**求索者之眼让眼泪在偏航、擦过或撞墙卡住时停下来重新找路，而不是只会普通追踪。**

普通追踪泪会朝目标拐弯；求索则会在必要时短暂停顿，再重新锁定附近敌人，必要时绕过障碍。

每枚眼泪最多重新求索 **3** 次。每次成功重新求索后伤害提高：

| 已求索次数 | 伤害倍率 |
| ---: | ---: |
| 0 | ×1.00 |
| 1 | ×1.15 |
| 2 | ×1.30 |
| 3 | ×1.50 |

求索时的寻路优先级如下：

1. 直线通畅则直飞
2. 否则会尝试绕障
3. 灵体泪仍可穿墙
4. 若被墙挡住又绕不过去，可能沿墙滑动；滑不出去则结束求索

## 注意

某些特殊泪不会参与这套求索，例如鲁多维科式环绕。
