## 效果

「似有所选」代表一份可以反复拒绝的道具选择：只要没有真正选择它，这份选择就不会消失，而会等待之后的道具机会再次出现。

选择同组的其他道具，或什么都不拿便离开房间，都算拒绝这份「似有所选」。之后遇到新的合适道具选择时，它会再次加入其中；如果同一房间内又出现新的道具机会，也可能立即回来。

例如：

**A + 似有所选**

选择 A 后，之后遇到 B 时可能变为：

**B + 似有所选**

如果仍然选择 B，它还会继续等待。只有真正选择「似有所选」所在的选择位，这一份等待才会结束。

拾取「似有所选」本身没有额外效果。

## 重置与轮换

重置不会消除一份尚未结束的「似有所选」。

例如：

**A + 似有所选**

使用 {{Collectible:105}} 后可能变成：

**B +（C / 似有所选）**

「似有所选」绑定的是右侧这个选择位，而不是底座此刻显示的道具。

因此：

- 选择 B 仍然算拒绝「似有所选」，它会继续等待。
- 选择右侧底座会获得当前显示的道具，并结束这一份「似有所选」。

能让一个底座轮换多个道具的效果也遵循相同规则。即使底座当前没有显示「似有所选」，只要它仍属于这份选择，拾取后就会结束对应的等待。

## 商品

商品形式的「似有所选」被拒绝后，会保留当时的实际售价。价格跟随这份选择，而不是后来承载它的普通底座。

例如，一份售价 **7¢** 的「似有所选」以后再次加入道具选择时，它自己的选择位仍按 **7¢** 结算；重置成其他道具也不会改变这份价格。

已经带有价格的普通商品不会成为等待中的「似有所选」重新加入的目标；它会继续等待之后合适的免费道具机会。

## 特殊联动

### {{Seija}}

受到 Seija 增幅时，每次「似有所选」重新加入一个选择，它所在的底座都会额外加入一个来自当前道具池的随机道具进行轮换。

**A + 似有所选**

会变为：

**A +（B / 似有所选）**

选择 A 时，这份「似有所选」继续等待；选择右侧轮换底座时，则获得当前显示的道具，并结束这一份等待。

## 注意

- 多份尚未结束的「似有所选」分别记录，并可以同时加入同一次道具选择。
- 一份「似有所选」可以加入本身已经含有「似有所选」的选择；多份之间不会互相合并。
- 同一房间内没有次数限制：只要之后又出现新的合适道具机会，刚刚被拒绝的「似有所选」就可以再次出现。
- 自然出现与后来重新出现的「似有所选」遵循完全相同的选择规则。

## 轶事

风味描述「请再看看罢」引用自《第五共和国》中的相关台词。

除这句风味描述外，道具名称与机制并不以该作品为原型。
