## 效果

**血仪刺刃让你永久献祭持有的道具，为选中的颜色充能；颜色达到 100% 后，其能力便会点亮。**

使用时：

1. 先选择要补充的颜色；
2. 再从自己持有的道具中选择一件献祭；
3. 确认后永久移除祭品，并消耗血仪刺刃的全部充能。

打开或取消选择不会消耗充能。界面会直接显示本次献祭能增加的准确百分比。

六种颜色均从 **0%** 开始，上限为 **200%**。未达到 100% 的颜色不会自然流失；已经点亮的颜色会在每次清理战斗房后失去 **10%**，低于 100% 后能力关闭。

## 六色能力

| 颜色 | 达到 100% 后 |
| --- | --- |
| 红 | +3 攻击 |
| 橙 | 清房奖励有 50% 概率额外生成一份普通掉落，不复制收藏品 |
| 黄 | 后续献祭获得的颜色进度 ×1.5 |
| 绿 | 获得飞行，并 +0.15 移速 |
| 蓝 | +1.5 射速；攻击命中后留下短暂水迹 |
| 紫 | 25% 概率免疫伤害；提高普通敌人变为精英的概率 |

六色可以同时点亮。超过 100% 的部分不会解锁新能力，只用于延长维持时间。

## 颜色与献祭

祭品品质决定基础进度：品质 0/1/2/3/4 分别提供 **35% / 50% / 70% / 100% / 140%**。

道具主色对同色提供完整效率，对色环相邻色提供 50%，次要关联通常提供 25%；没有关联时不提供进度。白、灰、黑等特殊颜色会按内部颜色映射折算。

最终进度为“品质基础进度 × 颜色效率”；黄色点亮时，再乘以 1.5。

## 精英敌人

击杀精英敌人会按其外观颜色补充少量对应进度。普通单色精英通常补充 10%；复合颜色会分配约 12%；彩虹精英为六色各 +3%，白色精英为六色各 +2%。

## 注意

- 血仪刺刃自身、任务道具、隐藏或非真实持有的道具不能被献祭。
- 每多持有一份血仪刺刃，点亮颜色的每房流失减少 2%，最低为 4%。
- 精英击杀进度只是维护补充；本道具的主要充能来源仍是献祭。
