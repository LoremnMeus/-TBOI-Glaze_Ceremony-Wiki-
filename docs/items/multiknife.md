## 效果

**倍增重刃会消耗当前全部充能挥出一刀；每多 1 格充能，刀刃的伤害和范围都会再次翻倍。**

- {{Battery}} 至少 **1** 格即可使用，并消耗当前全部充能
- {{Damage}} **1** 格造成 **100%** 角色攻击；每多 1 格，伤害再翻一倍
- 刀刃体积也随充能变大；充能很高时体积与碰撞会达到上限

### 充能与伤害

| 充能 | 伤害 |
| -: | ---: |
| 1 | 1× |
| 2 | 2× |
| 3 | 4× |
| 4 | 8× |
| 5 | 16× |
| 6 | 32× |

更高充能继续翻倍；彼列之书可将充能上限抬到 **12**。

## 特殊联动
