## 效果

**灵感的情绪是：平时看得到拿不到，濒死才成真。**

### 幻像何时出现

清理房间后约 **60%** 概率生成一个奖励幻像。

### 为什么越来越明显

生命越低，幻像越亮、越“实”。高生命时它们更像半透明诱惑；掉到危险线时才像真正的掉落。

### 怎样才能拿走

只有绝对生命降到约 **1** 格时，触碰才会把幻像实体化。生命更高时会被推开，拿不到。

### 可能变成什么

| 类型 | 相对常见度（概念） |
| --- | --- |
| 魂心 | 很高 |
| 双红心 / 镍币 / 充能钥匙 / 双炸弹 / 道具 | 较高 |
| 福袋 / 一角币 | 中等 |
| 金心 / 永恒心 / 金钥匙 / 金炸弹 | 较低 |

具体仍是加权随机，上表只帮助建立“常见 vs 稀有”的直觉。

## 使用技巧

先清房看有没有诱人的幻像道具；若值得为它赌命，再把生命压到可触碰线。
