## 效果

**再世纪把本局行为塑造成一个“世纪”，真正结束时留给下一局一次遗产与代价。玩家可以主动把时代推向某一侧。**

- 持有期间，六种世纪持续计分；达到形成阈值且明显领先时，会提示时代形成/转向
- 真正结束（通关或死亡）会结算；**重开 / 未存档退出不结算**
- 遗产只影响**下一局一次**

### 六种世纪

| 世纪 | 下一局大意 |
| --- | --- |
| 繁荣世纪 | 商店更强，但更贵 |
| 战争世纪 | 战备与玩家更强，敌人也更武装 |
| 丰饶世纪 | 生命资源暴增，挤占其他基础资源 |
| 技术世纪 | 电池与人工设施繁荣，天然资源变少 |
| 信仰世纪 | 天使/恶魔力量活跃，需要坚定站队 |
| 废墟世纪 | 带着重建物资开局，高级设施变稀 |

## 如何塑造世纪

想把时代推向某一侧时，本局多做对应行为；达到形成阈值且明显领先时会出现时代形成/转向提示。

| 世纪 | 本局主要推动行为 |
| --- | --- |
| 繁荣 | 进入商店、积累与花费硬币、高额购物 |
| 战争 | 清房与 Boss 战；无伤或较快清房额外加分；保持较高攻击 |
| 丰饶 | 增加心容器 / 魂心、治疗；满血清房；进 Boss 房时较满血 |
| 技术 | 拾取科技向道具、消耗主动充能、捡电池、使用老虎机等机械 |
| 信仰 | 进入天使/恶魔房并在其中拿道具、付出恶魔价、献祭、拾取钥匙碎片 |
| 废墟 | 在资源窘迫状态（低血、少硬币/钥匙/炸弹、道具偏少）下清房、换层或打 Boss |

## 轶事

- 名称来自游戏王「再世」系列；本道具会把本局世纪作为遗产留给下一局（非卡组「对方回合结束回收」的逐字复刻）。
