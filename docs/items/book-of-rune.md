## 效果

**卢恩之书的循环是：拾取送符文 → 用符文 → 本房记录 → 使用书按记录抽新符文。**

1. **首次拾取**生成 1 张随机符文，作为启动资源；之后再捡到副本通常不会重复送。
2. 在本房间亲自使用符文时，书记录 1 次，最多 **3** 次。
3. 使用卢恩之书：按当前记录数生成等量**随机**符文，并清空记录。
4. **换房清空**未兑现记录，所以要在同一房间内完成“用符文 → 用书”。

抽出的符文不一定与用掉的相同；这是兑换，不是原样返还。

持有符文时，还可以额外携带 1 张卡牌或药丸（类似入门套牌的额外槽体验）。

## 使用技巧

- 第一张启动符文很重要：先用它开门记录，再尽快用书兑现。
- 进房前先规划最多 3 次符文使用，避免换房清空。
- 需要卡牌/药丸双持时，身上留着符文就能多一个口袋位。
