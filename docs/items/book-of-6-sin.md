## 效果

**六罪论本身提供爆炸伤害免疫，对应“愤怒”；本局首次击败其余六种七宗罪时，会分别获得一次奖励。**

如果拾取六罪论前已经击败过其中某种罪，拾取后会立即补发对应奖励。

| 七宗罪 | 奖励 |
| --- | --- |
| 嫉妒 | 本局获得穿透与灵体泪 |
| 贪婪 | 生成 3 张随机卡牌 |
| 傲慢 | 生成 3 件随机道具，仅可选择其中 1 件 |
| 色欲 | 生成 1 张小丑卡 |
| 懒惰 | 本局所有商店的硬币价格 −1，可降至免费 |
| 暴食 | 生成 2 张红钥匙碎片 |
| 愤怒 | 无额外击杀奖励；六罪论本身已经提供爆炸伤害免疫 |
