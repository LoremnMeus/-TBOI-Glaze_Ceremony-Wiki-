## 效果

**六罪论把“七宗罪”拆成：封面已写好的愤怒，以及其余六罪的击杀掉落。**

常驻效果：免疫爆炸伤害。

**唯独愤怒没有击杀奖励——因为爆炸免疫已经写在封面上。**

其余六罪本局首次击败时领取奖励；若拾取时已经击败过，会立即补领。

| 罪 | 奖励 |
| --- | --- |
| 嫉妒 | **本局永久**：穿透与灵体泪（跨房、跨层保持） |
| 贪婪 | 生成 3 张随机卡牌 |
| 傲慢 | 随机道具三选一 |
| 色欲 | 生成 1 张小丑卡 |
| 懒惰 | **本局永久**：商店价格 −1（可减到免费；之后所有商店均生效） |
| 暴食 | 生成 2 张红钥匙碎片 |
| 愤怒 | **无击杀奖**（封面即爆炸免疫） |
