## 机制说明

## 效果

**每次使用黄金抽奖机花费 1 枚硬币进行一次抽奖。**

落空不会获得奖励，但会提高之后的中奖率；一旦中奖，连败积累清零并从最低概率重新开始。

奖励全部围绕黄金拾取物展开，其中极低概率可以获得巨型宝箱或奖杯。

## 如何运作

- 每次使用消耗 1 枚硬币。
- 初始中奖率为 10%。
- 每连续落空一次，下一抽中奖率提高 4 个百分点。
- 中奖率最高为 40%。
- 中奖后连败立即清零，之后重新从 10% 开始。

连败会在整局中跨房间、跨楼层保留，直到中奖为止。连续落空越多，主动道具图标的金色光晕与抖动也会越明显。

## 中奖率

| 连续失败 | 下一抽中奖率 |
| ---: | ---: |
| 0 | 10% |
| 1 | 14% |
| 2 | 18% |
| 3 | 22% |
| 4 | 26% |
| 5 | 30% |
| 6 | 34% |
| 7 | 38% |
| 8+ | 40% |

达到 8 次连败后已经触及上限，继续落空不会再提高概率。

::: tip 数值仍可能调整
上表与奖励权重是**当前默认**实现，仍可能随平衡微调；不要把它们当成永久不变的契约。
:::

## 特殊大奖

“特殊大奖”占中奖奖励的 1%，其中 95% 生成巨型宝箱，5% 生成奖杯。因此，在一次已经中奖的抽奖中，巨型宝箱与奖杯分别占 0.95% 和 0.05%。

| 当前中奖率 | 巨型宝箱 | 奖杯 |
| ---: | ---: | ---: |
| 10% | 0.095% | 0.005%（约 1 / 20,000） |
| 40% | 0.38% | 0.02%（约 1 / 5,000） |

这些数值表示当前这一次使用的最终概率，不包含此前连败过程的累计期望。

## 特殊联动

#### {{Collectible:34}}

每次使用的价格提高到 2 枚硬币。中奖率不变；中奖时会分别抽取两份候选奖励，并只生成预设档次更高的一份。这是“二选一取高”，不是双倍奖励。

#### {{Collectible:584}}

落空时会产生一枚黄金魂火，最多保留 3 枚；新的魂火会替换最早的一枚。魂火或它发射的泪弹命中敌人时有 12% 概率使其点金 90 帧。魂火会随连败变得更大、更亮，中奖后全部清除。

#### {{Collectible:356}}

额外触发不会进行第二次抽奖，也不会额外扣除硬币。

## 使用技巧

- **高连败时预留硬币。** 接近 40% 时，如果还有继续获得硬币的机会，保留多次尝试所需的资金通常更灵活。
- **中奖后重新判断是否继续。** 中奖会立刻把下一抽降回 10%，与已经连续落空多次时是完全不同的使用状态。
- **彼列书改善奖励，不改善中奖率。** 它提高每次尝试的费用，并在中奖后筛选奖励；不要把 2 枚硬币理解成更容易中奖。

## 细节与特殊情况

- 硬币不足时不会进行抽奖，不会扣钱，也不会增加连败。
- 多人游戏中，所有黄金抽奖机共用本局的同一条连败记录；任一玩家落空都会推进它，任一玩家中奖都会将它清零。
