## 机制说明

### 概览

{{Item:golden-slot}} 会花费一枚硬币进行一次抽奖。连续落空并不会白费：每次失败都会提高下一次的中奖率，直到中奖后重新开始。

中奖时会生成一种黄金奖励，从普通的黄金掉落物，到极低概率出现的巨型宝箱甚至奖杯。因此它更接近一台带有“连败补偿”的老虎机，而不是固定 10% 概率的纯随机按钮。

### 玩法

每次使用消耗 1 枚硬币。第一次尝试的中奖率是 10%；每连续失败一次，下一抽提高 4 个百分点：

| 连续失败 | 下一抽中奖率 |
| ---: | ---: |
| 0 | 10% |
| 1 | 14% |
| 2 | 18% |
| 3 | 22% |
| 4 | 26% |
| 5 | 30% |
| 6 | 34% |
| 7 | 38% |
| 8+ | 40% |

中奖率最高不会超过 40%。中奖后连败记录归零，下一次抽奖重新从 10% 开始。

### 奖励

一次中奖后，奖励按以下权重抽取：

| 奖励 | 中奖后的概率 |
| --- | ---: |
| 点金苍蝇 | 24% |
| 黄金硬币 | 18% |
| 黄金自爆炸弹 | 15% |
| 金心 | 11% |
| 金药丸 | 8% |
| 金电池 | 6% |
| 金炸弹 | 5% |
| 金钥匙 | 5% |
| 金饰品 | 4% |
| 巨型金药丸 | 3% |
| 特殊大奖 | 1% |

“特殊大奖”会进一步抽取：95% 生成巨型宝箱，5% 生成奖杯。奖杯并不是每次使用都有 5% 概率，而是需要先中奖、抽中 1% 特殊大奖，再命中特殊大奖中的 5%。

### 示例

第一次使用时只有 10% 中奖率。如果连续失败 5 次，第 6 次尝试的中奖率已经提高到 30%。

因此抽奖并不是完全独立的重复掷骰：失败得越久，下一次尝试越有吸引力。

### 联动

#### {{Collectible34}} 彼列之书

每次使用的价格提高到 2 枚硬币。中奖时会分别抽取两份候选奖励，并保留其中档次更高的一份，而不是生成双倍掉落。

#### {{Collectible584}} 美德之书

落空时会产生一枚黄金魂火，最多保留 3 枚；新的魂火会替换最早的一枚。魂火或它发射的泪弹命中敌人时有 12% 概率使其点金 90 帧。中奖后会清除这些黄金魂火。

### 使用技巧

如果只剩很少的硬币，是否继续投入取决于当前已经累积了多少次失败。刚中奖后重新开始时，下一抽回到最低概率；反过来，如果已经连续失败多次，多准备几枚硬币继续尝试，更容易利用已经建立的补偿。
