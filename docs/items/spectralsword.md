## 机制说明

## 效果

**使用后唤出妖鬼，可以从角色已有的能力中抽取灵质，再将灵质注入其他能力，重新分配角色的力量。**

- **属性灵质：** 调整角色的六项基础属性。
- **资源灵质：** 调整硬币、炸弹、钥匙及其携带上限。
- **概率灵质：** 调整恶魔房与星象房的出现概率。

抽取会降低对应数值并获得灵质，注入则消耗灵质提高数值。三类灵质互不通用。

使用方向键操纵妖鬼，按 **Q** 抽取、**E** 注入，按 **Ctrl** 退出。

## 调整规则

### 属性

每次抽取或注入 1 个属性灵质，对应属性会发生以下变化：

| 属性 | 调整幅度 |
| -- | ----- |
| 移速 | ±0.05 |
| 射速 | ±0.15 |
| 攻击 | ±0.25 |
| 射程 | ±0.75 |
| 弹速 | ±0.10 |
| 幸运 | ±1 |

各项属性的调整存在一定限制。

### 资源与上限

硬币、炸弹和钥匙每次可以与 **1 个资源灵质**交换。

也可以使用资源灵质调整携带上限。随着上限提高，每次调整的幅度会逐渐增大，例如从 **99** 提升至 **199**，再提升至 **299**。

### 房间概率

- **恶魔房与星象房：** 每次调整约 **5 个百分点**，消耗或获得概率灵质。
- **天使房：** 在恶魔房与天使房之间重新分配出现概率，不消耗灵质。
- **{{Collectible:498}}：** 将恶魔房与天使房概率合并调整。

## 特性

- 初次获得时没有灵质，需要先抽取才能注入。
- 房间中存在活跃敌人时无法使用。
- 完成的调整在失去妖刀后仍然有效。
