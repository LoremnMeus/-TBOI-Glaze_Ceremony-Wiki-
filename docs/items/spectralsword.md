## 效果

妖刀·逢魔通过三种彼此独立的灵质，把角色已有的属性、资源与房间概率在同类数值之间重新分配。

使用后唤出妖鬼并进入重塑界面。选择一个数值进行抽取会降低该数值并获得对应灵质；向其他数值注入同类灵质则会提高它。所有调整立即生效。

使用方向键移动妖鬼；按 Q 抽取当前数值，按 E 注入对应灵质，按 Ctrl 退出。

三类灵质分别用于：

- **属性灵质**：角色的六项基础属性。
- **资源灵质**：硬币、炸弹、钥匙及三者的携带上限。
- **概率灵质**：恶魔房与星象房概率。

天使房概率不消耗灵质，只重塑恶魔 / 天使之间的分配。

三类灵质不能互相替代。

### 属性

每次抽取或注入 1 个属性灵质，对应以下调整：

| 属性 | 每次调整 |
| --- | ---: |
| 移速 | 0.05 |
| 射速 | 0.15 |
| 攻击 | 0.25 |
| 射程 | 0.75 |
| 弹速 | 0.10 |
| 幸运 | 1 |

每项属性可以通过妖刀调整的总幅度有限。

抽取移速时，最终移速不能低于 0.10；抽取弹速时，最终弹速不能低于 0.60。

### 基础资源与上限

硬币、炸弹和钥匙均以 1:1 与资源灵质交换。

抽取 1 个对应资源会获得 1 个资源灵质；消耗 1 个资源灵质则获得 1 个所选资源。

资源灵质也可以用于调整对应资源的携带上限。调整始终针对玩家看到的**当前实际上限**，并沿十进制「全 9」阶梯扩展（设计上不设人为封顶；底层仅受 32 位有符号整数存储边界约束）：

| 当前上限区间 | 每次调整 |
| --- | ---: |
| 0–9 | ±1 |
| 9–99 | ±10（如 99↔89、9↔19） |
| 99–999 | ±100（如 99↔199、999↔899） |
| 999–9999 | ±1000（如 999↔1999） |
| 更高 | 继续按下一数量级 ×10 |

合法节点形如：0…9、19…99、199…999、1999…9999…；上行与下行在阶梯上严格可逆。若下一档会超过引擎整数存储上限，则直接落到该上限（可到达，不会因此拒绝注入）。

提高上限消耗 1 个资源灵质；降低上限则获得 1 个资源灵质。

如果降低后的携带上限会低于当前已经持有的对应资源数量，或会低于 0，则无法进行这次抽取。

### 房间概率

恶魔房与星象房概率以最终 HUD 显示值为准，默认每次 5 个百分点，并使用概率灵质。靠近 0% / 100% 边界时，最后一步会补到边界（例如 3% 抽取到 0%，96% 注入到 100%），仍只结算 1 个概率灵质。概率灵质只在恶魔房与星象房之间流动。

天使房概率不使用灵质：它重塑当前总 Deal 在恶魔 / 天使两侧的分配，总 Deal 不变。因此天使显示提高 5 个百分点时，恶魔显示会对应降低 5 个百分点。默认仍按 5 个百分点步进；若剩余不足一步，则直接吃满到 100% 天使分配（或反向降到 0%）。若原版规则在该位置存在状态跳变（例如 0% ↔ 50% / 100%），妖刀允许一次跨过该台阶。若当前状态下无论怎样调整转化都无法改变天使显示，则该节点暂时不可操作。

星象房行显示「与原生 Stat HUD 对齐的缓存概率」以及「相对该缓存的实时差值」（例如 `21.0% +5.0%`）。差值为 0 时不显示后缀。Q/E 仍按实时星象概率边界调整永久修正；差值会包含望远镜镜片等所有来源，不单是妖刀自己的修改。原生 HUD 在新层或读档后刷新时，缓存会重新对齐，后缀随之消失。

星象房节点仅在原版 Stat HUD 会显示星象概率时可用（需开启对应选项，且已解锁星象房）。

在原版 Found HUD 不提供恶魔房与天使房概率的楼层，这两项无法进行调整。

## 注意

- 初次获得妖刀·逢魔时没有额外灵质；所有灵质都需要先通过抽取得到。
- 房间内存在活跃敌人时无法打开重塑界面。
- 已完成的属性、资源上限与房间概率调整不会因为失去妖刀·逢魔而失效；再次获得后可以继续在原有结果上调整。
- 基础资源的增减在操作时立即结算。
