## 效果

**娇嫩的花是一件资源管理道具：保护花朵，再决定把它送给谁。**

- 每份道具提供 **1** 朵花；每层开始时，花朵数量重置为当前持有的娇嫩的花数量。
- 受到敌人伤害会失去 1 朵花；花耗尽后头饰消失。
- 靠近可收礼对象时会举起花朵；再贴近即可送出并消耗 1 朵。

## 收花者与回礼

店长的回礼会随所在房间和店长种类变化。

| 收花者 | 回礼 |
| --- | --- |
| 撒旦雕像 | 约 **3–7** 个红箱子，并降低本房间内带价交易物的价格 |
| 天使雕像 | 约 **3–6** 个白箱子，并使下一层天使房**转化率**提升 |
| 普通店长 | **2–4** 个福袋 |
| 上吊店长 | 打开通往本层随机**非普通房**的传送门 |
| 错误店长 | 生成 1 个错误道具 |
| 商店店长 | 生成 1 台补货机 |
| 商店上吊店长 | 降低本房间内带价商品价格（普通正价格约 **7 折**） |
| 隐藏/超隐店长 | 生成 1 个随机道具 |
| 隐藏/超隐上吊店长 | **3–5** 张卡牌 |

商店与隐藏房中的店长会按房间类型切换到对应奖励行。

## 注意

- 只有被判定为敌人来源的伤害会损失花朵；献血机等非敌人伤害不会损失花朵。
- 重复持有会提高每层可保存与重置的花朵数量。

## 轶事

- 灵感来自《空洞骑士》娇嫩之花任务：花很脆弱，也可以送给其他 NPC。
