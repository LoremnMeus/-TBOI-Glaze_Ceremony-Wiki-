## 效果

娇嫩的花要求角色保护好花朵，再把它送给楼层里愿意接受的人，以换取不同的回礼。

- 拾取时获得 1 朵花；进入下一层时补充花朵。
- 被敌人伤害时失去 1 朵花。
- 靠近合适的对象后会举起花朵；接触对方即可送出。

## 回礼

| 收花者 | 回礼 |
| --- | --- |
| 撒旦 | 生成数个红箱子，并降低房间内的交易价格 |
| 天使 | 生成数个白箱子，并使下一层更容易出现天使房 |
| 普通店主 | 生成若干福袋 |
| 商店店主 | 生成补货机，或降低房间内的商品价格 |
| 隐藏房店主 | 生成随机道具或卡牌 |
| 错误店主 | 生成一个错误道具 |

重复持有会让角色能够保存并补充更多花朵。
