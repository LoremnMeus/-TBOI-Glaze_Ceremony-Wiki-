## 玩法

「不稳定体」让伊甸在受伤时把构筑抖落在地：随机被动会掉出来，必须及时捡回；否则可能被普通敌人偷走并强化对方。

## 规则

- 受到敌人伤害时，随机掉落最多 **3** 件被动/跟班（任务与隐藏类除外），触碰可重新拾取。
- 非 Boss 敌人可以抢走地上的脱落道具并变强；击杀后可取回。
- Boss 不会偷窃脱落道具。
