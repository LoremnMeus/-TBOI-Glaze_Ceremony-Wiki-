## 玩法

**青不会自己开火。你拾取道具，是为了决定谁替她开火。**

{{Character:sp-w-qing}} 无法进行普通攻击。她会一直控制一个指挥准星，并通过随身的 {{Item:blue-print}} 制造、改装和部署飞行器。

普通角色获得攻击道具后，通常直接强化自己；青则可以把这些道具组织进不同的机体，让每架飞行器拥有自己的攻击方式和战斗属性。

因此，一局里青的基本循环是：

> **获得道具 → 组装机体 → 安排出战顺序 → 指挥机群作战。**

你控制的不是一架越来越复杂的超级飞行器，而是一支可以不断重新编排的机群。

## 第一次使用青

开局时，先**长按蓝图**打开管理面板。

第一架 **空行零号·试作型** 不要求投入底座道具，因此即使刚刚开始游戏，也可以先建立最基本的攻击能力。

之后拿到新的道具时，可以再回到蓝图考虑它的用途：

- 想让一架机体拥有这个道具的攻击能力，就把它作为**模块**；
- 想扩大新机体的模块空间与整体性能，可以把一件道具作为**底座**；
- 已经完成的配置以后仍然可以重新调整，不需要在第一次拾取道具时永久决定它的用途。

制造、底座品质、模块占用、原型以及具体兼容规则见 {{System:blueprint-air-flight}}。

首次打开蓝图时还可以进入交互式教程。教程使用模拟机体与材料，不会消耗当前游戏中的真实资源。

## 出战与指挥

制造出机体，并不代表所有机体都会同时战斗。青拥有有限的**控制带宽**；编队从前向后分配，**队列越靠前越优先出战**。没有分到带宽的机体回到身边**待命**，不会主动索敌或开火，归属于它的战斗型宝宝也会一起停火。

仓库回答「我拥有哪些机体？」，编队回答「现在由谁上场？」。默认带宽与精确分配见 {{System:blueprint-air-flight}}。

进入战斗后，青本人主要只做两件事：**决定机群在哪里**，以及**决定机群打哪里**。这两件事彼此独立。

### 阵型：它们在哪里？

- **巡航**：飞行器离开青身边，自行展开行动。
- **护卫**：飞行器收拢到青的两翼，在角色附近保持队形。

### 火控：它们打哪里？

- **自动**：飞行器自行寻找可以攻击的目标。
- **压制**：飞行器不再自行选敌，而是集中攻击准星指向的位置。

| 阵型 | 火控 | 适合的情形 |
| --- | --- | --- |
| 巡航 | 自动 | 普通清房，让机群自行展开索敌 |
| 护卫 | 自动 | 需要机体集中在青附近时 |
| 巡航 | 压制 | 保持展开，同时集中攻击指定目标 |
| 护卫 | 压制 | 把火力收拢在身边并集中轰击一个位置 |

护卫并不等于压制，压制也不会把机体自动叫回身边。**一个决定位置，一个决定攻击目标。**

- **攻击方向 / 按住鼠标左键**：移动指挥准星。
- **Ctrl / 鼠标中键**：在巡航与护卫之间切换。
- **鼠标右键 / 短按蓝图**：在自动与压制之间切换。
- **长按蓝图**：打开蓝图管理面板。

准星始终存在；切换阵型或火控不会让它消失，颜色会随当前指挥状态变化。

## 构筑机群

对青来说，拿道具时还要多想一层：**「它应该属于哪一架机体？」**

刚开始不需要急着规划完整舰队。先让第一架基础机有稳定输出，往往比为了未来构筑而暂时没有战斗力更实际。

随着道具增加，再考虑机体之间的分工，例如：一架主力输出，一架完全不同的特殊武器，一架围绕宝宝或特殊模块，一架作为编队靠后的备用。

高品质道具用作底座，意味着放弃它在该机体上作为特殊模块的机会，换取更多槽位与更好的整体性能。真正需要构筑的不是青本人，而是机群之间的分工。兼容细节见 {{System:blueprint-air-flight}}。

## {{Collectible:619}}：冗余设计

持有 {{Collectible:619}} 时，每架飞行器额外获得一个镜像模块槽，可复制一件你当前持有的兼容道具。详细规则（是否占额度、能否多架共引、失去原件后如何失效等）见 {{System:blueprint-air-flight}}。

## 使用技巧

- **先保证有东西能打。** 第一架基础机不需要真实底座，适合尽快建立初始火力。
- **编队顺序就是备用计划。** 超过带宽的机体没有浪费；调整优先级即可改变当前出战组合。
- **护卫解决站位，压制解决目标。** 出问题先问：要改「机体在哪」，还是「机体打谁」。

## 特殊互动

青对一些与自己、飞行器或过去有关的道具有专属名称与评价。例如，她会把 {{Item:air-flight}} 称为「末日之羽」，把 {{Item:air-terror}} 称为「末日之泪」。

这些文字用于表现角色状态，不代表对应道具一定拥有额外的蓝图能力。具体能否作为模块以及模块实际效果，仍以 {{System:blueprint-air-flight}} 为准。

## 注意

- **青本人无法进行普通攻击。** 即使攻击类道具仍显示在物品栏中，也不能因此让本人恢复普通泪弹攻击。
- **只有作为模块加入对应机体的道具**，才会把蓝图中的战斗能力提供给那架机体；作为底座主要决定机体规模与基础性能。
- **待命机体以及属于它的战斗型宝宝不会参与当前战斗。**
- **并非所有道具都拥有蓝图模块效果**；具体兼容情况见 {{System:blueprint-air-flight}}。
