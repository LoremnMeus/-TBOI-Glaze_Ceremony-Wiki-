## 效果

**旅者会把当前道具池里几份“可化作魂火”的可能，摆成环绕你的虚影；你亲手挑走其中一份，其余就当作没走过。**

- 使用后在周围**固定位置**浮起最多 **5** 个可召唤道具虚影（半透明、缓缓上下飘动，背后蓝色火焰）。
- 靠近时更清晰，远离时更淡；接触其中一个：举起该道具 → 圣光 → 收起并化为魂火，**只牺牲这一件**。
- **「牺牲」**意味着将该道具从本局道具池中**移除**（之后池里不再出现它），而不是只消耗一次抽取。
- 其余虚影消散，不改变道具池。
- 离开房间且未选择：全部取消，无事发生。

## 注意

- 若筛不出任何可化作魂火的候选，角色会失望，也不会生成虚影。
